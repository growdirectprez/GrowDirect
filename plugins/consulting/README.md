# consulting — IBM BCS Methodology Plugin

Consulting skills from the IBM Business Consulting Services lineage (2006 era).
Plug retailer evidence into a preserved structural frame and produce
Big-4-grade deliverables.

## Skills

- **`consulting:retail-diagnostic`** — Clarks-pattern 7-section retail
  diagnostic deck. Financial baseline → two theme drill-downs → priorities
  → roadmap → case for action.
- **`consulting:it-architecture-options`** — Morrisons-pattern multi-option
  IT architecture evaluation. Business targets → requirements frame →
  legacy implications → three parallel option evaluations → side-by-side
  summary.

## Status

v0.1 scaffold — methodology preserved in Brain wikis; SKILL.md files define
triggers and workflow; deck-skeleton templates (pptx masters) to be built
in Sprint 2.

## Methodology provenance

Both skills are rooted in deliverables Geoffrey C. Lyle produced or reviewed
during his IBM BCS era (2006). The original .ppt files are preserved as
reference material; only the structural methodology — not the client-specific
content — is codified here.

Authoritative methodology articles live in the GrowDirect vault:
