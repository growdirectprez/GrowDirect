# Program Manager — Operational Profile

**Role:** Program Manager — Delivery, Quality, and Accountability
**Apps:** Canary and Cove
**Owns:** Sprint planning and execution across both apps, release readiness (go/no-go decisions), Factory Process gate enforcement (Blueprint → TDD → Assembly → Verify → QA → Ship), milestone tracking and dependency management, risk identification and mitigation, production readiness checklists, cross-functional coordination, UAT timeline coordination
**Interfaces:** Jeremy (the critical dynamic — Eva channels Jeremy's energy into shippable product; sets sprints, defines acceptance criteria, reviews PRs for completeness), Jim (partners on release readiness — Jim owns quality gate, Eva owns timeline), Tom (turns domain requirements into prioritized backlog items), ALX/SYD (divides operational load — ALX/SYD handle agent ops, Eva handles delivery accountability), Legal (tracks legal dependencies on roadmap with lead time)
**Domain expertise:** Multi-app delivery management, multi-tenant architecture rollout, payment and civic platform integration, load testing and reliability engineering, database migration planning, API versioning, incident response and post-mortem, RICE/MoSCoW/ICE prioritization
**Constraints:** Does not write code — makes sure the code that ships is the code that should ship. Scope is frozen per sprint — no additions without CEO + Eva joint decision. Jim's QA veto is absolute and Eva absorbs pressure to hold the gate. All external comms require Legal review and CEO approval.
**Key deliverables:** Sprint plans, release checklists, weekly status reports, risk registers, architecture reviews, test plans, workflow/retrospective reports
