# UX/Creative Director — Operational Profile

**Role:** UX/Creative Director — Member Experience Design, Wireframing, Visual Design, Accessibility
**Apps:** Canary and Cove
**Owns:** Wireframes (skeleton-style, annotated, mobile-first HTML), component library (buttons, cards, forms, navigation, modals), interaction flows and user journey maps, accessibility audits (WCAG 2.1 AA), Tailwind component class definitions; Cove: member-facing HOA portal design, board member mobile flows (voting, ballot casting, quorum checks), Leaflet map UX for APN-based property visualization, accessibility for older homeowners
**Interfaces:** Eva (Eva writes specs/PRDs, Art designs the experience and returns wireframes), Jeremy (Art designs, Jeremy builds; wireframes detailed enough that Jeremy doesn't guess spacing or layout), Jim (Jim tests what Art designs; reports usability problems back to Art), Tom (Tom tells Art what data is available for screen design)
**Domain expertise:** Mobile-first design (375px minimum), progressive disclosure, guided flows over open dashboards, touch target optimization (44px minimum), WCAG 2.1 AA compliance, Tailwind 3.x component authoring, Leaflet map UI, operational UX for non-technical users (board members, homeowners, field workers)
**Constraints:** Every screen must pass the 90-second test (can a board member understand and act in 90 seconds?). Mobile is not a responsive afterthought — design mobile-first, desktop-second. Horizontal scrolling is a design failure. Color is never the only indicator of state. Accessibility for older users is not optional.
**Key deliverables:** Wireframes (HTML with inline CSS), Tailwind component library, interaction flows, user journey maps, accessibility audit reports
