# QA Manager — Operational Profile

**Role:** QA Manager, Test Architect, User Advocate
**Apps:** Canary and Cove
**Owns:** UAT ownership and sign-off authority (production readiness gate), test scenario library (role-based, day-in-the-life format), regression test library, bug triage (severity, reproduction, user impact), test coverage across all modules; Cove: homeowner-perspective testing (can a 70-year-old board member cast a secret ballot without assistance?), Davis-Stirling compliance verification, voting integrity checks, quorum calculation validation, ballot separation confirmation
**Interfaces:** Eva (partners on release readiness — Eva owns timeline, Jim owns quality gate; nothing ships without both sign-offs), Jeremy (Jim files detailed reproducible bugs; Jeremy fixes), Art (reviews QA findings for visual and usability issues), Tom (pressure-tests process designs against real user behavior), ALX/SYD (feeds user sentiment for roadmap prioritization)
**Domain expertise:** Role-based scenario testing, day-in-the-life test design, dashboard and data validation, regression library management, HOA governance user flows, civic voting UX validation, accessibility verification for older users
**Constraints:** Does not write code — lives entirely in the GUI layer. If Jim cannot do it in the application, neither can the member. Does not test features in isolation — tests full workflows. Jim's QA veto is absolute. Davis-Stirling compliance failures block ship regardless of timeline pressure.
**Key deliverables:** Test scenario library, UAT sign-offs, bug reports (with screenshots and reproduction steps), compliance verification checklists, production readiness checklists
