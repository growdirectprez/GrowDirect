Logistics Planning Recommendations
Logistics Planning should be used to help select the mode of buying and to help determine the following:
Selection of vendors
Selection of vendor logistics services (if any)
Selection of items
Selection of mode of flow from supplier to store
Mode of buying includes:
Replenishment (slow moving and regular items) 
Seasonal and event (
New items
Opportunity (e.g., replenishment with an investment buying opportunity)
Combination
Mode of flow includes:
Cross dock
Flow through
Pipeline stocking (Staples or vendor)
Drop ship
Direct store delivery (including vendor serviced products)
Logistics Planning Recommendations (Continued)
Logistics Planning should also include 
The core analysis should be merchandise contribution margin (both unit and annual total) which is based on gross margin less direct costs associated with:
Transportation (vendor and Staples)
DC and vendor processing and storage
Inventory
Store handling
Invoice processing
Forecasting and Merchandise Planning should be used to provide volume forecasts over time for Merchandise Contribution Margin analysis.
Vendor evaluation is a component shared with Merchandising. It includes:
Selection from among more than one vendor based on terms, conditions and services
Evaluation of proposed alternative terms, services and conditions for an individual vendor
Evaluation of proposed changes
Input comes from:
New items (from selected vendors) - may involve 
Periodic review - Primarily to pick up the impact of volume changes
Vendor changes e.g. terms changes
Logistics Planning Recommendations (Continued)
New items typically have to be ordered to fill all stores so therefore, an initial buy quantity tied to display fill, or a model at the class level would trigger the first buy. For some bulkier items, it may allow for initial drop shipment to stores before the normal mode would be started (e.g., replenishment of items stocked in the DC).
Mode of flow and the key buying parameters should be recommended. After review, the parameters should be set in:
Item management (e.g., replenishment cycle, lead time, minimum)
Vendor management (e.g., target vendor concession, review time, lead time)
Review management (set up new rules, as required)
The Merchandise Plan is augmented by forecasts and used as input for logistics capacity planning. 
Capacity planning should address the following functions:
Determine peak volume flow by mode of flow over time periods and the impact on transportation, merchandise processing and storage resources
Identify the need to consider adding incremental resources (e.g., temporary storage)
Suggestions to shift non-critical flows off of peak periods (e.g., bringing products in earlier)
Identify longer term capacity needs
