Item Management
Item Management Recommendations
Item management is the repository for all data related to items so that it can be supplied consistently to all operational processes and performance monitoring.
Data enters the repository from the 
The change / maintain process makes authorized changes to any or all of the elements of item data in the repository. There is an audit trail maintained on changes.
The deletion process supports authorized deletion of items in the repository, subject to restrictions, e.g., no active inventory in stores. There is an audit trail maintained for deletions.
All audit trails include who made the change and when.
Item data in the repository itself supports the operational processes and performance monitoring. 
Support for operational processes includes:
Validating entries, e.g., is it a valid item?
Supplying descriptive data from numeric ID
Changes cause a history to be created. The history is maintained not only to provide an extended audit trail, but also to provide the appropriate
