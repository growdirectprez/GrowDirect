Brain The Bridge Layer

Obsidian vault with curated knowledge. The only layer both environments can read. Content engine manages intake and prevents duplicates.

Knowledge Flows

Claude Code session → Memory Bus (auto) → content-engine ingest (manual) → Brain wiki article → Cowork session reads it
Cowork session → content-engine ingest (manual) → Brain wiki article → Claude Code reads it

Gaps What needs fixing

Memory Bus → Brain sync

Memory Bus captures session learnings automatically, but distilling them into Brain wiki articles is manual. A content-engine command to extract key memories would close this gap.

pgvector half-wired in Cove

Proposals, Documents, and Meetings have Vector(1024) columns but embeddings are never generated on create. Only knowledge_chunks actually works. Need SQLAlchemy event listeners or service-layer hooks.

GitNexus MCP deferred

Index has 7959 symbols but no MCP server to expose tools. CLAUDE.md documents tools that don't resolve. Need to either wire the MCP or strip the instructions.

Content Engine (CLI)

Manages knowledge flow into Brain. Prevents duplicate docs.

registry check "<topic>" — search before creating
registry build — rebuild topic index
ingest <file> -p <project> — create raw-intake note
triage <dir> --batch 20 — batch classify files
scan / dupes / clean / flatten — filesystem ops
