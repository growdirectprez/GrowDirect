Universal Event Notarization — Six-Node Architecture

Staged Immutability Pipeline with Proof-of-Work Base-Layer Anchoring
FIG. 1 — System Architecture Overview
NODE 1

Universal Webhook Origination

Any network source: payment processors (Square, Shopify, Clover), healthcare systems (Epic, Cerner), supply chain (FedEx, SAP), legal registries, insurance platforms, government agencies. Raw payload transmitted via standard webhook POST. Source-agnostic, protocol-independent event stream.

NODE 2

API Gateway & Queue Publication

Single point of ingestion. HMAC-SHA256 signature validation. SHA-256 hash of raw payload computed at receipt. Publishes to durable message queue with fan-out to three independent subscriber processes.

INNOVATION: Triple Subscriber Pattern — decoupled consumption, no cross-dependency, each subscriber has independent persistence model
SUB 1 — NODE 3

Hash & Seal

  • Write-once evidence store
  • SHA-256 hash + chain link
  • Append-only, never altered
  • Bilateral verify: hash vs. sender log
  • Sub-second latency (T+0)
IMMUTABILITY
SUB 2 — NODE 4

Parse & Route

  • Structured, queryable store
  • Indexed by merchant partition
  • Mutable — enrichment allowed
  • Replayable from Sub 1
  • Rebuild on deploy
RESILIENCE
SUB 3 — NODE 5/6

Merkle & Ordinal

  • Batch hash aggregation
  • Merkle tree → root hash
  • Ordinal inscription on Bitcoin
  • Key custody by treasury
  • ~10 min confirmation
PERMANENCE
