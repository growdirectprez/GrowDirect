Animated Logo — Chirp Alert

The sound waves animate when an alert fires — the bird "chirps." Idle state shows a gentle bob with faint static waves. Alert state fires the waves outward with bright amber signal color.

Idle State (Quiet)

Gentle bob · waves barely visible

Alert State (Chirping!)

Beak animates · waves burst in amber · red alert dot pulses

Full Animation Sequence — Continuous Loop

Stacked animated lockup · chirp loop with alert dot · use for loading states, notifications, splash screens

Animation Specifications

Idle

Gentle 3s ease-in-out vertical bob (2px). Sound waves at 10–20% opacity with slow fade. Bird feels alive but calm.

Chirp / Alert

1.8s cycle. Beak opens ±4°. Three waves burst outward staggered 150ms apart. Waves use Signal Amber (#F59E0B → #FBBF24). Red alert dot pulses and rings expand.

Timing

Wave 1: 0ms delay, full opacity. Wave 2: 150ms delay, 60% opacity. Wave 3: 300ms delay, 40% opacity. Creates a natural sound-radiating-outward feel.

Don't

Don't loop the chirp endlessly in the UI. Fire on alert, then return to idle. Max 3 chirps per notification event.

Usage Guidelines

Do

Use the dark background version (#0D1117) as the primary. Neutral bird, bright alert waves.

Don't

Use the animated chirp on static media (print, business cards). Save it for screens only.

Do

Let the sound waves carry the brand energy. Bird stays calm, waves do the talking.

Don't

Mix neutral bird colors with alert amber on the bird body. Amber is reserved for waves only.

Do

Use the animated version for: app loading, notification toast, dashboard alert headers.

Don't

Loop chirp animation continuously. Fire → 2–3 chirps → return to idle. Respect the user's attention.
