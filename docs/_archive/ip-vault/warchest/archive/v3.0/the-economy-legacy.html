01
Treasury Mints
GrowDirect deploys BTC — earned through mining, not purchased — to inscribe the Genesis Pool. The reward never leaves. It becomes permanent assets on the time chain.
02
Protocol Licenses
Smart contract layer enforces licensing automatically via L402. Every validation call against the canonical registry costs sats. No PDF. No lawyers. Lightning executes the license.
03
Royalty Compounds
Sats flow back to treasury. Treasury grows. Merchant nodes mint their own Ordinals — from their own keys — and El Jeffe earns a royalty stream on every validation. Forever.
The closed loop: Treasury mints Ordinals → Protocol writes to chain → Smart contract licenses validation → Royalties grow treasury → Merchants build their own treasury → They mint their own Ordinals → El Jeffe earns the royalty stream.

Open source protocol. Proprietary registry. Perpetual royalty. No one can replicate the blocks already written.
