With the principle established, reviewed Art's 5 patent visual HTML diagrams. All treated the three persistence stores as peers — needed to show the sovereignty hierarchy. ## Key Decisions

1. **No hard FK from merkle_batches → namespace_registrations** — inscription exists on Bitcoin before Postgres cache row; cache cannot constrain ledger
2. **chain.sequence UNIQUE constraint is a guardrail, not governance** — if chain and index disagree, chain wins
3. **Bitcoin stores canonical name, Postgres caches derived name** — indexer appends `.jeffe` suffix when caching
4. **Sovereignty Line concept** — everything above is rebuildable cache, everything below is permanent ledger
5. **Cockroach Test** — system's value proposition survives total infrastructure failure
