Ingestion Layer

Source Network (Any Webhook Provider)

Square, Shopify, Epic, FedEx, or any system capable of HTTP POST webhooks. Generates events with UUID identifiers and signs payloads with HMAC-SHA256.
HTTPS POST + HMAC-SHA256
↓ raw webhook payload + signature ↓

API Gateway / Webhook Receiver

Validates HMAC signature. Computes SHA-256 hash of raw payload. Assigns event ID. Publishes to message queue. Returns 200 OK. Single entry point — all events enter here.
Node.js + Express
Queue Layer — Critical Path

Message Queue (Durable, Ordered)

Fan-out point. Three independent consumer groups. At-least-once delivery. Message ordering within merchant partition. Each subscriber tracks its own offset independently.

Subscriber Layer — Triple Independent Consumers

Sub 1: Hash & Seal

Write-once evidence store. SHA-256 hash + hash chain link. Append-only — never altered, never deleted. Bilateral verification source. Rebuildable from Bitcoin inscriptions.
PostgreSQL JSONB · Write-Once L1 INDEX

Sub 2: Parse & Route

Structured schema. Queryable, indexed. Mutable — enrichment allowed. Replayable from Sub 1. Emits to detection engine. Entirely rebuildable from L1.
PostgreSQL Tables · Partitioned L2 INDEX

Sub 3: Merkle & Ordinal

Batch hash accumulator. Merkle tree construction. Ordinal inscription. Key custody. Bitcoin base layer anchoring. Bedrock — survives total infrastructure failure.
Node.js Worker · Bitcoin Core LEDGER

Persistence Layer — Sovereignty Hierarchy

Evidence Store

Immutable index. JSONB raw payloads. Hash chains. UNIQUE constraint prevents duplicates. Source of truth for bilateral verification and replay/rebuild. Rebuildable from Bitcoin.
PostgreSQL JSONB · L1 Index

Structured Store

Queryable business data. Partitioned by merchant_id. Indexed for search. Feeds dashboard and analytics. Entirely derivable from Evidence Store.
PostgreSQL Tables · L2 Index

₿ Bitcoin Time Chain

Inscription IDs. Merkle roots. .jeffe namespace identity. Chain sequence history. Block timestamps. Survives server failure. Survives company failure. Permanent.

External Verification (No Trust Required)

Bilateral Verification Path

Source network compares its send log against evidence store hash. Merkle proof path verifiable on any Bitcoin block explorer. No intermediary required. Survives total system failure — Bitcoin anchor is independent. The verification path is: Send Log ↔ Evidence Hash (L1) ↔ Merkle Proof ↔ Block Explorer (₿).
