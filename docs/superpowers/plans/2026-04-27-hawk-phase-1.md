# Hawk Phase 1 — Case Management Card Factory

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Hawk's core case management engine — schema, seed data, wizard-driven intake, card generation, investigator UI, and MCP server — as the multi-class case surface replacing Fox Lite.

**Architecture:** Hawk extends the `app` schema (via `AppBase`) following the Fox pattern — `hawk_` table prefix, models in `canary/models/hawk/`, service in `canary/services/hawk/`. Cards carry pgvector embeddings for memory bus ingest. The wizard state machine is server-side: incident type selection loads a JSONB template that drives required-field enforcement before case status can advance.

**Tech Stack:** Python 3.12 / Flask 3 / SQLAlchemy 2.0 `Mapped[]` / PostgreSQL 17 + pgvector / Jinja2 templates / Tailwind CSS / Alpine.js

**Spec:** `docs/superpowers/specs/2026-04-27-hawk-bull-design.md` (sections 1-3, 5-6, 8 Phase 1)

# canary/models/hawk/reference.py
"""Hawk reference tables — incident types, sources of information."""

from __future__ import annotations

from typing import Optional

from sqlalchemy import Boolean, String, Text
from sqlalchemy.dialects.postgresql import JSONB
from sqlalchemy.orm import Mapped, mapped_column

from canary.models.base import AppBase, generate_uuid


class HawkIncidentType(AppBase):
    """Incident type definition with wizard template.

    type_code is the PK — no UUID. These are seeded reference data.
    wizard_template is JSONB defining required fields per incident type.
    """

    __tablename__ = "hawk_incident_types"

    type_code: Mapped[str] = mapped_column(String(60), primary_key=True)
    incident_class: Mapped[str] = mapped_column(
        String(30), nullable=False,
        comment="critical_smart_alert|external|internal|incident",
    )
    de_pv_flag: Mapped[Optional[str]] = mapped_column(
        String(5), nullable=True,
        comment="DE|PV|NULL — only for internal class",
    )
    display_name: Mapped[str] = mapped_column(String(120), nullable=False)
    wizard_template: Mapped[dict] = mapped_column(JSONB, nullable=False, default=dict)
    resolution_track: Mapped[str] = mapped_column(
        String(10), nullable=False,
        comment="internal|external",
    )
    active: Mapped[bool] = mapped_column(Boolean, nullable=False, default=True)

    def __repr__(self) -> str:
        return f"<HawkIncidentType {self.type_code} ({self.incident_class})>"


class HawkSource(AppBase):
    """Source of information for case intake.

    source_id is UUID PK. source_code is the lookup key (CCTV, EBR, GLI, etc.).
    """

    __tablename__ = "hawk_sources"

    id: Mapped[str] = mapped_column(String(36), primary_key=True, default=generate_uuid)
    source_code: Mapped[str] = mapped_column(String(30), nullable=False, unique=True)
    source_class: Mapped[str] = mapped_column(
        String(10), nullable=False,
        comment="internal|external",
    )
    display_name: Mapped[str] = mapped_column(String(120), nullable=False)

    def __repr__(self) -> str:
        return f"<HawkSource {self.source_code}>"
```

# canary/models/hawk/cases.py
"""Hawk case management tables — multi-class investigation records."""

from __future__ import annotations

from datetime import datetime
from typing import Optional, TYPE_CHECKING

if TYPE_CHECKING:
    from canary.models.hawk.subjects import HawkSubject
    from canary.models.hawk.actions import HawkAction
    from canary.models.hawk.timeline import HawkTimeline
    from canary.models.hawk.cards import HawkCard
    from canary.models.hawk.compliance import HawkComplianceObligation

from sqlalchemy import (
    DateTime,
    ForeignKey,
    Index,
    String,
    Text,
    func,
)
from sqlalchemy.orm import Mapped, mapped_column, relationship

from canary.models.base import AppBase, TenantMixin, AuditMixin, SoftDeleteMixin, generate_uuid


class HawkCase(AppBase, TenantMixin, AuditMixin, SoftDeleteMixin):
    """Hawk case — multi-class investigation record.

    incident_class: critical_smart_alert | external | internal | incident
    case_status flow: open → investigating → pending_review → escalated → closed | referred_to_le
    de_pv_flag: DE (Dishonesty/Ethics) | PV (Policy Violation) | NULL — internal class only

    Note: TenantMixin provides merchant_id. The explicit merchant_id declaration
    below overrides TenantMixin's version with a specific FK target. This matches
    the FoxCase pattern (fox/cases.py:52) which does the same override.
    """

    __tablename__ = "hawk_cases"

    id: Mapped[str] = mapped_column(String(36), primary_key=True, default=generate_uuid)
    merchant_id: Mapped[str] = mapped_column(
        String(36), ForeignKey("merchants.id"), nullable=False,
    )
    location_id: Mapped[str] = mapped_column(
        String(36), ForeignKey("locations.id"), nullable=False,
    )
    incident_class: Mapped[str] = mapped_column(
        String(30), nullable=False,
        comment="critical_smart_alert|external|internal|incident",
    )
    incident_type: Mapped[str] = mapped_column(
        String(60), nullable=False,
        comment="FK-like ref to hawk_incident_types.type_code",
    )
    de_pv_flag: Mapped[Optional[str]] = mapped_column(
        String(5), nullable=True,
        comment="DE|PV|NULL — internal class only",
    )
    case_status: Mapped[str] = mapped_column(
        String(20), nullable=False, default="open",
        comment="open|investigating|pending_review|escalated|closed|referred_to_le",
    )
    opened_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now(), nullable=False,
    )
    closed_at: Mapped[Optional[datetime]] = mapped_column(
        DateTime(timezone=True), nullable=True,
    )
    opened_by: Mapped[str] = mapped_column(String(255), nullable=False)
    assigned_to: Mapped[Optional[str]] = mapped_column(
        String(255), nullable=True, comment="User ID if assigned",
    )
    source_id: Mapped[Optional[str]] = mapped_column(
        String(36), ForeignKey("hawk_sources.id"), nullable=True,
    )
    fox_case_id: Mapped[Optional[str]] = mapped_column(
        String(36), ForeignKey("fox_cases.id"), nullable=True,
        comment="Populated if incident_class=EBR (Fox bridge)",
    )
    chirp_alert_id: Mapped[Optional[str]] = mapped_column(
        String(36), nullable=True,
        comment="Originating Chirp alert if system-initiated",
    )
    bull_exception_id: Mapped[Optional[str]] = mapped_column(
        String(36), nullable=True,
        comment="Originating Bull exception if vendor case (Phase 3)",
    )
    narrative: Mapped[Optional[str]] = mapped_column(Text, nullable=True)
    card_id: Mapped[Optional[str]] = mapped_column(
        String(36), nullable=True,
        comment="FK to hawk_cards — populated post-wizard completion",
    )

    # Relationships (forward-declared, wired as models are added)
    subjects: Mapped[list["HawkSubject"]] = relationship(
        back_populates="case", cascade="all, delete-orphan",
        foreign_keys="HawkSubject.case_id",
    )
    actions: Mapped[list["HawkAction"]] = relationship(
        back_populates="case", cascade="all, delete-orphan",
        foreign_keys="HawkAction.case_id",
    )
    timeline: Mapped[list["HawkTimeline"]] = relationship(
        back_populates="case", cascade="all, delete-orphan",
        foreign_keys="HawkTimeline.case_id",
    )
    compliance_obligations: Mapped[list["HawkComplianceObligation"]] = relationship(
        back_populates="case", cascade="all, delete-orphan",
        foreign_keys="HawkComplianceObligation.case_id",
    )

    __table_args__ = (
        Index("ix_hawk_cases_merchant_status", "merchant_id", "case_status"),
        Index("ix_hawk_cases_merchant_class", "merchant_id", "incident_class"),
        Index("ix_hawk_cases_merchant_type", "merchant_id", "incident_type"),
        Index("ix_hawk_cases_location", "location_id"),
        Index("ix_hawk_cases_assigned", "assigned_to"),
        Index("ix_hawk_cases_fox_bridge", "fox_case_id"),
    )

    def to_dict(self) -> dict:
        return {
            "id": self.id,
            "merchant_id": self.merchant_id,
            "location_id": self.location_id,
            "incident_class": self.incident_class,
            "incident_type": self.incident_type,
            "de_pv_flag": self.de_pv_flag,
            "case_status": self.case_status,
            "opened_at": self.opened_at.isoformat() if self.opened_at else None,
            "closed_at": self.closed_at.isoformat() if self.closed_at else None,
            "opened_by": self.opened_by,
            "assigned_to": self.assigned_to,
            "narrative": self.narrative,
        }

    def __repr__(self) -> str:
        return f"<HawkCase {self.id[:8]} {self.incident_type} ({self.case_status})>"

# canary/models/hawk/subjects.py
"""Hawk subjects — people/entities of interest linked to cases."""

from __future__ import annotations

from datetime import date
from typing import Optional, TYPE_CHECKING

if TYPE_CHECKING:
    from canary.models.hawk.cases import HawkCase

from sqlalchemy import Date, ForeignKey, Index, String, Text
from sqlalchemy.orm import Mapped, mapped_column, relationship

from canary.models.base import AppBase, TenantMixin, AuditMixin, SoftDeleteMixin, generate_uuid


class HawkSubject(AppBase, TenantMixin, AuditMixin, SoftDeleteMixin):
    """Person or entity of interest in a Hawk case.

    subject_type: employee | customer | vendor | unknown
    For employees: employee_id links to app.employees.
    For vendors: vendor_entity_id is the Counterpoint vendor code.
    For external parties: external_name + ID fields.

    Uses TenantMixin + SoftDeleteMixin to match FoxSubject pattern.
    Note: TenantMixin provides merchant_id; not declared explicitly here.
    """

    __tablename__ = "hawk_subjects"

    id: Mapped[str] = mapped_column(String(36), primary_key=True, default=generate_uuid)
    case_id: Mapped[str] = mapped_column(
        String(36), ForeignKey("hawk_cases.id"), nullable=False,
    )
    subject_type: Mapped[str] = mapped_column(
        String(20), nullable=False,
        comment="employee|customer|vendor|unknown",
    )
    employee_id: Mapped[Optional[str]] = mapped_column(
        String(36), ForeignKey("employees.id"), nullable=True,
    )
    vendor_entity_id: Mapped[Optional[str]] = mapped_column(
        String(60), nullable=True,
        comment="Counterpoint vendor code (C008/F012 vendor master)",
    )
    external_name: Mapped[Optional[str]] = mapped_column(String(255), nullable=True)
    external_dob: Mapped[Optional[date]] = mapped_column(Date, nullable=True)
    external_id_type: Mapped[Optional[str]] = mapped_column(String(60), nullable=True)

# canary/services/hawk/case_service.py
"""Hawk case management service — CRUD, status FSM, timeline."""

from typing import Dict, List, Optional

from sqlalchemy.orm import Session

from canary.models.hawk import (
    HawkCase, HawkIncidentType, HawkSource, HawkTimeline,
    HawkSubject, HawkAction,
)

# Status FSM: allowed transitions
VALID_TRANSITIONS: Dict[str, List[str]] = {
    "open": ["investigating"],
    "investigating": ["pending_review", "escalated"],
    "pending_review": ["escalated", "closed", "referred_to_le"],
    "escalated": ["closed", "referred_to_le"],
    "closed": [],
    "referred_to_le": [],
}

VALID_STATUSES = frozenset(VALID_TRANSITIONS.keys())

VALID_SUBJECT_TYPES = frozenset({"employee", "customer", "vendor", "unknown"})

VALID_INTERNAL_ACTIONS = frozenset({
    "CLOSED_UNFOUNDED", "CORRECTIVE_ACTION", "INTERVIEWED_NO_CASE",
    "QUIT_BEFORE_INTERVIEW", "QUIT_DURING_INTERVIEW", "REPORTED_TO_ATF",
    "TERMINATED_PROSECUTED", "TERMINATED_RELEASED", "UNDER_INVESTIGATION",
})

VALID_EXTERNAL_ACTIONS = frozenset({
    "CLOSED_UNFOUNDED", "PROSECUTED", "RELEASED_ADULT",
    "RELEASED_TO_GUARDIAN", "RELEASED_TO_POLICE", "UNDER_INVESTIGATION",
})


class HawkCaseService:
    """Session-injected service for Hawk case management."""

    def __init__(self, session: Session):
        self.session = session

    def create_case(
        self,
        merchant_id: str,
        location_id: str,
        incident_type: str,
        opened_by: str,
        narrative: Optional[str] = None,
        source_code: Optional[str] = None,
        assigned_to: Optional[str] = None,
        chirp_alert_id: Optional[str] = None,
    ) -> HawkCase:
        # Look up incident type to derive class and de_pv_flag
        it = self.session.query(HawkIncidentType).filter_by(
            type_code=incident_type
        ).one_or_none()
        if it is None:
            raise ValueError(f"Unknown incident type: {incident_type}")

        source_id = None
        if source_code:
            src = self.session.query(HawkSource).filter_by(
                source_code=source_code
            ).one_or_none()
            if src:
                source_id = src.id

        case = HawkCase(
            merchant_id=merchant_id,
            location_id=location_id,
            incident_class=it.incident_class,
            incident_type=incident_type,
            de_pv_flag=it.de_pv_flag,
            case_status="open",
            opened_by=opened_by,
            assigned_to=assigned_to,
            source_id=source_id,
            chirp_alert_id=chirp_alert_id,
            narrative=narrative,
        )
        self.session.add(case)
        self.session.flush()

        # Auto-create timeline entry
        self._append_timeline(
            case_id=case.id,
            merchant_id=merchant_id,
            event_type="created",
            actor_id=opened_by,
            description=f"Case opened: {it.display_name}",
            event_data={"incident_type": incident_type, "incident_class": it.incident_class},
        )

        return case

    def get_case(self, case_id: str) -> Optional[HawkCase]:
        return self.session.query(HawkCase).filter_by(id=case_id).one_or_none()

    def list_cases(
        self,
        merchant_id: str,
        status: Optional[str] = None,
        incident_class: Optional[str] = None,
        limit: int = 50,
        offset: int = 0,
    ) -> List[HawkCase]:
        q = self.session.query(HawkCase).filter_by(merchant_id=merchant_id)
        if status:
            q = q.filter_by(case_status=status)
        if incident_class:
            q = q.filter_by(incident_class=incident_class)
        q = q.order_by(HawkCase.opened_at.desc())
        return q.offset(offset).limit(limit).all()

    def advance_status(self, case_id: str, new_status: str, actor_id: str) -> HawkCase:
        case = self.session.query(HawkCase).filter_by(id=case_id).one()
        allowed = VALID_TRANSITIONS.get(case.case_status, [])
        if new_status not in allowed:
            raise ValueError(
                f"Invalid status transition: {case.case_status} → {new_status}. "
                f"Allowed: {allowed}"
            )

        old_status = case.case_status
        case.case_status = new_status

        if new_status in ("closed", "referred_to_le"):
            from datetime import datetime, timezone
            case.closed_at = datetime.now(timezone.utc)

        self._append_timeline(
            case_id=case.id,
            merchant_id=case.merchant_id,
            event_type="status_change",
            actor_id=actor_id,
            description=f"Status changed: {old_status} → {new_status}",
            event_data={"old_status": old_status, "new_status": new_status},
        )

        return case

    def add_subject(
        self,
        case_id: str,
        subject_type: str,
        actor_id: str,
        employee_id: Optional[str] = None,
        vendor_entity_id: Optional[str] = None,
        external_name: Optional[str] = None,
        notes: Optional[str] = None,
    ) -> HawkSubject:
        if subject_type not in VALID_SUBJECT_TYPES:
            raise ValueError(f"Invalid subject type: {subject_type}")

        case = self.session.query(HawkCase).filter_by(id=case_id).one()
        subj = HawkSubject(
            case_id=case_id,
            subject_type=subject_type,
            employee_id=employee_id,
            vendor_entity_id=vendor_entity_id,
            external_name=external_name,
            notes=notes,
        )
        self.session.add(subj)
        self.session.flush()

        self._append_timeline(
            case_id=case_id,
            merchant_id=case.merchant_id,
            event_type="note_added",
            actor_id=actor_id,
            description=f"Subject added: {subject_type}",
            event_data={"subject_id": subj.id, "subject_type": subject_type},
        )

        return subj

    def add_action(
        self,
        case_id: str,
        action_code: str,
        actor_id: str,
        notes: Optional[str] = None,
    ) -> HawkAction:
        case = self.session.query(HawkCase).filter_by(id=case_id).one()

        # Determine track from incident class
        if case.incident_class in ("internal",):
            track = "internal"
            valid = VALID_INTERNAL_ACTIONS
        else:
            track = "external"
            valid = VALID_EXTERNAL_ACTIONS

        if action_code not in valid:
            raise ValueError(
                f"Invalid action code '{action_code}' for {track} track. "
                f"Valid: {sorted(valid)}"
            )

        action = HawkAction(
            case_id=case_id,
            action_code=action_code,
            action_track=track,
            actioned_by=actor_id,
            notes=notes,
        )
        self.session.add(action)
        self.session.flush()

        self._append_timeline(
            case_id=case_id,
            merchant_id=case.merchant_id,
            event_type="action_added",
            actor_id=actor_id,
            description=f"Action: {action_code}",
            event_data={"action_id": action.id, "action_code": action_code, "track": track},
        )

        return action

    def get_timeline(self, case_id: str) -> List[HawkTimeline]:
        return (
            self.session.query(HawkTimeline)
            .filter_by(case_id=case_id)
            .order_by(HawkTimeline.occurred_at.asc())
            .all()
        )

    def get_wizard_template(self, incident_type: str) -> dict:
        it = self.session.query(HawkIncidentType).filter_by(
            type_code=incident_type
        ).one_or_none()
        if it is None:
            raise ValueError(f"Unknown incident type: {incident_type}")
        return it.wizard_template

    def _append_timeline(
        self,
        case_id: str,
        merchant_id: str,
        event_type: str,
        actor_id: str,
        description: str,
        event_data: Optional[dict] = None,
    ) -> HawkTimeline:
        event = HawkTimeline(
            case_id=case_id,
            merchant_id=merchant_id,
            event_type=event_type,
            actor_id=actor_id,
            description=description,
            event_data=event_data,
        )
        self.session.add(event)
        return event
```

The card service:
- Queries case + subjects + actions to build structured markdown
- Constructs frontmatter JSONB from case entity tags
- Creates a `HawkCard` record
- On regeneration: invalidates previous version, increments version
- Links card to case via `case.card_id`
- Appends timeline event
- Vector embedding is NOT computed here (async, separate concern — memory bus ingest)

```python
# canary/services/hawk/card_service.py
"""Hawk card generation — structured case summaries for the intelligence substrate."""

from datetime import datetime, timezone
from typing import Optional

from sqlalchemy.orm import Session

from canary.models.hawk import (
    HawkCase, HawkCard, HawkSubject, HawkAction, HawkTimeline,
)


class HawkCardService:
    """Generates and manages Hawk case cards."""

    def __init__(self, session: Session):
        self.session = session

    def generate_card(self, case_id: str, actor_id: str) -> HawkCard:
        case = self.session.query(HawkCase).filter_by(id=case_id).one()
        subjects = self.session.query(HawkSubject).filter_by(case_id=case_id).all()
        actions = self.session.query(HawkAction).filter_by(case_id=case_id).all()

        # Invalidate previous card if exists
        version = 1
        prev_card = (
            self.session.query(HawkCard)
            .filter_by(case_id=case_id)
            .filter(HawkCard.invalidated_at.is_(None))
            .one_or_none()
        )
        if prev_card:
            prev_card.invalidated_at = datetime.now(timezone.utc)
            version = prev_card.card_version + 1

        # Build card body
        card_body = self._build_card_body(case, subjects, actions)

        # Build frontmatter
        frontmatter = self._build_frontmatter(case, subjects)

        card = HawkCard(
            case_id=case_id,
            card_body=card_body,
            frontmatter=frontmatter,
            card_version=version,
        )
        self.session.add(card)
        self.session.flush()

        # Link card to case
        case.card_id = card.id

        # Timeline event
        event = HawkTimeline(
            case_id=case_id,
            merchant_id=case.merchant_id,
            event_type="card_generated",
            actor_id=actor_id,
            description=f"Card v{version} generated",
            event_data={"card_id": card.id, "card_version": version},
        )
        self.session.add(event)

        return card

    def _build_card_body(self, case: HawkCase, subjects, actions) -> str:
        lines = []
        lines.append(f"## {case.incident_type.replace('_', ' ').title()}")
        lines.append("")
        lines.append(f"**Class:** {case.incident_class}")
        if case.de_pv_flag:
            lines.append(f"**Classification:** {case.de_pv_flag}")
        lines.append(f"**Status:** {case.case_status}")
        lines.append(f"**Opened:** {case.opened_at.isoformat() if case.opened_at else 'unknown'}")
        lines.append("")

        if case.narrative:
            lines.append("### Narrative")
            lines.append("")
            lines.append(case.narrative)
            lines.append("")

        if subjects:
            lines.append("### Subjects")
            lines.append("")
            for s in subjects:
                name = s.external_name or s.employee_id or s.vendor_entity_id or "Unknown"
                lines.append(f"- **{s.subject_type.title()}:** {name}")
                if s.notes:
                    lines.append(f"  - {s.notes}")
            lines.append("")

        if actions:
            lines.append("### Actions")
            lines.append("")
            for a in actions:
                lines.append(f"- **{a.action_code}** ({a.action_track}) — {a.actioned_by}")
                if a.notes:
                    lines.append(f"  - {a.notes}")
            lines.append("")

        return "\n".join(lines)

    def _build_frontmatter(self, case: HawkCase, subjects) -> dict:
        subject_types = list({s.subject_type for s in subjects})
        employee_ids = [s.employee_id for s in subjects if s.employee_id]
        vendor_ids = [s.vendor_entity_id for s in subjects if s.vendor_entity_id]

        fm = {
            "card_type": "hawk_case",
            "case_id": case.id,
            "merchant_id": case.merchant_id,
            "location_id": case.location_id,
            "incident_class": case.incident_class,
            "incident_type": case.incident_type,
            "de_pv_flag": case.de_pv_flag,
            "case_status": case.case_status,
            "opened_at": case.opened_at.isoformat() if case.opened_at else None,
            "subject_types": subject_types,
        }
        if employee_ids:
            fm["employee_ids"] = employee_ids
        if vendor_ids:
            fm["vendor_ids"] = vendor_ids
        return fm
```

## Notes — Spec Drift and Decisions

**TenantMixin + explicit merchant_id:** `HawkCase` declares `merchant_id` explicitly despite inheriting `TenantMixin`. This follows the `FoxCase` pattern (`fox/cases.py:52`) which does the same override — SQLAlchemy 2.0 allows the explicit column to override the mixin's declared_attr. Verified as working in production. Not a bug.

**65 vs 63 incident types:** The spec header says "65 incident types" but the detailed taxonomy (section 3.1) totals 17 + 7 + 30 + 9 = 63. The plan seeds 63. The two-type gap appears to be a spec summary error. Flag for founder if exact count matters.

**`attach_evidence` MCP tool deferred:** The spec lists `attach_evidence` as a Phase 1 canary-hawk tool. However, evidence attachment requires the Fox evidence chain (`fox_evidence` table), which is Phase 2 work (Fox bridge). The tool is intentionally deferred to Phase 2 when `fox_evidence.hawk_case_id` FK is added.

**`card_id` FK intentionally omitted:** `hawk_cases.card_id` has no FK constraint to `hawk_cards` to avoid circular dependency (case creates card, card references case). Application-level consistency enforced by `HawkCardService`.

**`source_id` nullable:** Spec doesn't explicitly mark `source_id` as nullable, but not every case has a known source. Plan makes it nullable — sensible default.

**`incident` class action track:** Spec says incident class cases "may use either track." Plan currently routes all non-internal classes to the external track. If an `incident` class case needs internal-track actions, the service will need a track override parameter. Deferred until a real use case surfaces.
