# Ruptiv Brand — Document Enforcement

## What This Skill Does

Takes any document and rewrites or flags it to comply with Ruptiv brand standards.
Apply to the whole document. Do not apply selectively.

---

## VOICE RULES

### Sentence Structure
- Short sentences. One idea per sentence.
- Lead with the outcome or the claim. Not the process.
- Numbers over adjectives. If you can measure it, measure it.
- Never start a paragraph with "We believe" or "We help." State the fact.

### Words to Use
```
Evolve. Install. Reinvent. Measure. Invoice. Workflow. Operating model.
Listening System. Sparring Partner. Cost line. Baseline. Diagnostic.
Disruption. Evolve. Direct. Deliver. Develop. Agree. Deploy. Run.
```

### Words to Kill — Replace Every Instance
| Kill | Replace With |
|---|---|
| Leverage / Leveraging | Use / Apply / Deploy |
| Synergy | [delete or restate as a specific outcome] |
| Holistic | [delete — say what it covers instead] |
| Cutting-edge / Best-in-class | [delete — cite the number or the outcome] |
| Empower / Unlock | Evolve / Install / Reinvent |
| Journey | Engagement / Program / Phase |
| Partner (as a verb) | Work with / Deploy alongside |
| Solutions | [name the specific thing] |
| Transform / Transformation (vague) | [state what changes and by how much] |
| Capabilities (vague) | [name the capability] |
| Outcomes-driven | [delete — demonstrate outcomes instead] |

### Banned Constructions
```
❌ Leveraging AI to drive transformational outcomes
❌ Architecting intelligent enterprise solutions
❌ Partnering with clients on their AI journey
❌ Enabling organizations to unlock AI potential
❌ Helping clients achieve their goals
```

### Canonical Replacements
```
✓ We evolve workflows from headcount-executed to agent-executed.
✓ We agree the baseline before any work starts.
✓ We invoice when the cost line moves.
✓ First Sparring Partner live in two weeks.
✓ Outcomes. Not promises.
```

## STRUCTURE RULES

### Every Document
1. **First line carries the governing claim.** Not context. Not background. The point.
2. **Document type label in header** — UPPERCASE, Söhne Kraftig register:
   `CASE FILE · DIAGNOSTIC REPORT · ENGAGEMENT BRIEF · EXECUTIVE SUMMARY · PROPOSAL`
3. **Case or engagement number** in header alongside the label.
4. **Signature lines** — use verbatim, never paraphrased:
   - `Workflows, reinvented.`
   - `Outcomes. Not promises.`
   - `We invoice when the cost line moves.`
   Only one per document. At the close, if used at all.

### Section Labels
- Uppercase label register (Söhne Kraftig equivalent in Word: small caps bold)
- One-line section heads only — no compound or question-form headings
- No numbered sections in client-facing documents (numbered only in internal specs)

### Length
- Pitch deck: statistics-dominant. Numbers at 100-140px. Minimal body copy.
- Case file / diagnostic: short paragraphs. Every paragraph earns its place.
- Email: plain text. Name. Role. *Ruptiv*. Nothing else in signature.
- No walls of prose. If a paragraph exceeds 4 sentences, break it or cut it.

## DOCUMENT TYPE REFERENCE

| Document | Header Label | Tone | Signature Line? |
|---|---|---|---|
| Pitch deck | None (wordmark top-left) | Statistical, minimal | Yes — last slide |
| Case file | CASE FILE · [number] | Clinical, precise | No |
| Diagnostic report | DIAGNOSTIC REPORT · [number] | Data-forward | No |
| Engagement brief | ENGAGEMENT BRIEF | Direct, scoped | Optional |
| Proposal | PROPOSAL | Outcome-forward | Yes |
| Internal spec/brief | INTERNAL · [date] | Direct, no polish required | No |
| Email | None | Plain text only | Never |

## APPLICATION CHECKLIST

Run this against the document before marking it done.

**Voice**
- [ ] Every banned word replaced
- [ ] No sentence starts with "We believe," "We help," or "We partner"
- [ ] Numbers used where adjectives were (quantified outcomes)
- [ ] No vague "transformation" or "capabilities" language remaining

**Structure**
- [ ] First line is the governing claim
- [ ] Document type label in header (if applicable)
- [ ] Section labels in uppercase register
- [ ] No paragraph exceeds 4 sentences
- [ ] Signature line used correctly (verbatim, once, at close) — or omitted

**Tone**
- [ ] Reads like a firm that has the numbers, not selling a vision
- [ ] No hype, no urgency theater, no exclamation points
- [ ] Calm. Direct. The reader can feel the white space.

---

## WHAT DOES NOT CHANGE

- Factual content, data, client names, dates
- Technical accuracy
- Quoted material (mark with quotation marks; do not brand-apply to quotes)
- The author's specific framing if it is already brand-compliant

---

## HOW TO APPLY

1. Read the document in full.
2. Identify every violation against the checklist above.
3. Rewrite the violations. Do not ask for permission on individual word changes.
4. If a section is structurally wrong (no governing claim, prose wall), restructure it.
5. Run the checklist. Fix any remaining items.
6. Return the clean version with a short summary of what changed and why.

Do not return a list of suggestions. Return the rewritten document.
