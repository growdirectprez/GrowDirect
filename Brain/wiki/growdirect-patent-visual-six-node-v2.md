# Patent Schematic — Six-Node Architecture v2.0 (FIG. 1, historical)

Rendered SVG schematic — the **v2.0** version of FIG. 1 for Patent Application 63/991,596. Superseded by [[Brain/wiki/growdirect-patent-visual-architecture-v3|Architecture Visual v3.0]] but retained for patent prosecution history and to show architectural evolution.

## What the Figure Depicts

The original six-node Universal Event Notarization pipeline as drawn at filing preparation time. Same six nodes as v3.0 but with labeling that was later reconciled against Pitch Spine v0.4 and the TSP PRDs.

## Why It's Kept

1. **Prosecution history** — patents file on the schematic at a point in time. The v2.0 is the version of record for the initial filing (February 26, 2026); v3.0 incorporates post-filing refinements.
2. **Claim mapping** — some claims reference the v2.0 node numbering directly.
3. **Evolution narrative** — the delta between v2.0 and v3.0 illustrates how the naming reconciliation sprint (B-059 TSP PRD delivery) crystallized the canonical terminology.

## Differences from v3.0

- Node labels not yet aligned with Sub 1/2/3 TSP naming
- No explicit upward rebuild arrows
- Queue fan-out less detailed
- No Bitcoin timing annotations
