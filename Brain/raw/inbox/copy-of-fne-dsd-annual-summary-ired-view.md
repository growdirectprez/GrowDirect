## Glossary
| DSD iRED (invoice risk evaluation data) |
| --- |
| DELIVERY Metrics |
| VPInv = value per invoice - similar to POS SCA/SRA data = VPC |
| VPItm = value per item on invoice -  similar to POS SCA/SRA data = VPI |
| IPInv = items per invoice - similar to POS SCA/SRA data = IPC |
| CREDIT Metrics |
| VPInv = value per invoice - similar to POS SCA/SRA data = VPC |
| VPItm = value per item on invoice -  similar to POS SCA/SRA data = VPI |
| IPInv = items per invoice - similar to POS SCA/SRA data = IPC |
| COMBINED Metrics |
| Delivery VPItm (minus) Credit VPItm = A $ VALUE WHICH SHOULD BE NEGATIVE credit should be higher than delivery |
| VALUE (divided by) Delivery VPItm = A % VALUE WHICH SHOULD BE NEGATIVE |
| Delivery value (divded by) sales value = A % VALUE |
| Vendor specific comparisons – both delivery dollars and sales values |
| Category specific comparisons – both delivery dollars and sales values |
| SKU specific comparisons – both delivery dollars and sales values |
| Credit invoice ratio to delivery invoices = 1 credit invoice per every “X” delivery invoices |
| Credit value ratio = 1 credit dollar per every “X” delivery dollars |
| Credit Itm ratio = 1 credit item per every “X” delivery dollars |
