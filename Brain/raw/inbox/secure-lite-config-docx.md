Administration

Executive

* Role is delivered out of the box with the following capabilities no changes to the permissions after initial configuration \*
* EBR Dashboard \*
* Store Model Outlier available using out of the box SRA metrics
* Case Results Dashboard \*
* Key Actor Profile lookups (Store / Cashier)
* Quick Start questions

Analyst

* Role is delivered out of the box with the following capabilities no changes to the permissions after initial configuration \*
* CRDM is out of the box using the SDL process no resourcing of field aliases or enumerations for EBR or Case Management after initial set up
* Create one main calendar fiscal or Gregorian to drive all calendar functions configured during initial set up
* Analyst Dashboard \*
* Store Model Outlier access
* Manage users with application credentials and assigns data policies and permission groups manually, no SSO
* User data uploads
* No access to files app
* No designer access – development of new reports or dashboards would be consulting
* Predefined Risk Dictionary searches \*
* Access to ad hoc search composer
* Predefined set of analytics in the Work Item Composer ability to enable / disable each analysis and manage the parameters of the underlying search \*
* Access to Metric search for out of the box searches, but no Metric Manager access
* No access to user tasks
* No access to Teams
* No access to Permission Groups
* No access to data policy, set up location data restrictions if used during initial set up changes would be managed through the hierarchy itself
* No access to export manager
* No access to developer mode, Job system, Service Manager
* No access to Data Management menu
* Access to Fact Board and Internal EBR Case Management
* Access to Data Load Console

Investigator

* Role is delivered out of the box with the following capabilities no changes to the permissions after initial configuration \*
* Has access to work items module
* Access to Investigator EBR and Case dashboards
* Quick start questions, no search composer
* Case Management access
* Key actor profile look ups
* Can receive notifications and view reports
