Channel

A channel is a set of properties that you can use to configure BizTalk Messaging Services to process a document that it receives. Channels can be created for a messaging port or a distribution list. Once a channel has processed a document, the document is transported to the destination specified in the associated messaging port or the messaging ports in the associated distribution list. You can create one or more channels for a messaging port or distribution list.

The above section was taken from the Biztalk Help file.

Creating the Channel for the Retail Biztalk Resource Kit:

1.  Open Biztalk Messaging Manager

2.  Under 'Search for Other Items', Click 'Message Ports.'  Then click 'Search Now'.  Doing this will provide a list of available Message Ports implemented in Biztalk.

3.  To create a new Channel right mouse click on the Message Port named: 'FILE_4690_To_ActiveStore' and select 'New Channel>From Organization' from the pop up menu.

4.  The New Channel Wizard will appear.  In the name text box type  'FILE_4690_To_ActiveStore_Channel'.  Type the comments as you see below.

5.  Click Next and enter Source Organization information in the wizard.  Organization.

- Select the 'Organization' Option Button and click the 'Browse' Button.  The following windows will appear:

-Select 'StoreTransaction_org' as the source organization and click 'OK'

6.  Click 'Next' to enter 'Inbound Document' details in the Channel wizard.

-Enter the 'Inbound document definition name:' by clicking the 'browse' button.  The following window will appear.

- Select the 'StoreTransaction_DocDef' document definition and click 'OK'  Document Definitions

7.  Click 'Next' to enter 'Outbound Document' details in the Channel wizard. 

- Select the 'ActiveStore_DocDef' by clicking the 'Browse' button  Document Definition

- Activate the 'Map inbound document to outbound document' by clicking the checkbox.  Click the 'Browse' button to select the appropriate map from the webDAV.

- We created the map 'sys2act.xml' in the Map section of this document and placed it in the ResourceKitMaps directory of the webDAV.  

8.  Click 'Next' to enter 'Document Logging' details in the Channel wizard. 

8.  Click 'Next' to enter 'Advanced Configuration' details in the Channel wizard. 

9.  Click the 'Finish' button to complete the creation of the Channel.
