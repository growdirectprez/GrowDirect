Message Ports

A messaging port is a set of properties that you can use to configure BizTalk Messaging Services to transport documents to a specified destination by using a specified transport service. The documents that a messaging port transports originate from the source that you specify in an associated channel. You can create multiple channels for a single messaging port to send documents from many sources to the same destination.

A messaging port can be configured to send documents to a designated destination organization, an XLANG schedule, or a destination application.

The above section was taken from the Biztalk Help file.

Creating the Message Port for the Retail Biztalk Resource Kit:

1.  Open Biztalk Messaging Manager

2.  Under 'Search for Other Items', Click 'Message Ports.'  Then click 'Search Now'.  Doing this will provide a list of available Message Ports implemented in Biztalk.

3.  To create a new Message Port right mouse click the right pane of the Biztalk Messaging Manager and select 'New Message Port> To An Organization'.  Or in the select in the menu bar: File>New>Message Port> To An Organization.  Or CTRL+R.

4.  Follow the New Message Port Wizard: Enter Message Port General Information:

5.  Enter Destination Organization details

- Select the Organization Option and Click the 'Browse' button.  A window will pop up and show the organizations we created in an earlier process of this kit.  Organization

- Select 'ActiveStore_org' and click the 'OK' button.

- The next step is to select the primary transport method type and Address.

- Transport type is FILE and Address is the location on disk that the file will arrive on the disk.  When done click 'OK'  It is recommended that you create a directory structure that looks like the following on your hard-drive:  C:\Kit\Out and C:\Kit\In.  The address would look like: file://C:\kit\out\Activestore.xml.

6.  Click 'Next' and the Select Envelope Information screen appears.

- Select 'ActiveStore_Env' from the 'Envelope Information' drop down combo box.  The 'Organization Identifier' information should already be entered.  Envelope

7.  Click 'Next' and the Security Information screen appears.

- Enter any security information you might require and click 'Finish' to complete the creation of the new Message Port.

NOTE:  When completing the creation of the Message Port you will be taken to the creation of a Channel.  Channel
