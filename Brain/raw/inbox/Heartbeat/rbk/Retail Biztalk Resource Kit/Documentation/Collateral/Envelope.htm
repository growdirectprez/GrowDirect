Envelopes

An envelope encapsulates electronic business data for transport. An envelope typically consists of header and footer information, or of header information only. The envelope properties that you specify provide Microsoft BizTalk Server 2000 with information that the server needs to either open inbound interchanges or create outbound interchanges. When you create an envelope, you specify an envelope format; for certain types of formats, you also can select an envelope specification.

The above section was taken from the Biztalk Help file.

Creating Envelopes for the Retail Biztalk Resource Kit:

This section will show you how to create an Envelope in Biztalk Messaging Manager.  We will create two Envelopes.  One for ActiveStore and another for Systech.

1.  Open Biztalk Messaging Manager

2.  Under 'Search for Other Items', Click 'Envelopes.'  Then click 'Search Now'.  Doing this will provide a list of available Envelopes implemented in Biztalk.

3.  To create a new Envelope right mouse click the right pane of the Biztalk Messaging Manager and select 'New Envelope'.  Or in the select in the menu bar: File>New>Envelope.  Or CTRL+E.

4.  Type in the following information:

- In the Envelope name text box type: 'ActiveStore_Env'.   Click and activate 'Envelope specification' check box.  Click the 'Browse' button and select the ActiveStore file from the WebDAV Repository.

6.  Click 'OK' to complete the creation of the Envelope.

7.  Follow the same instructions for creating the StoreTransaction Envelope.  Use 'Systech_Env' for the Envelope name text box and select 'SystechDocSpec.xml' from the webDAV Repository Reference.

WebDAV Repository

WebDAV is an abriviation for "Web-based Distributed Authoring and Versioning". It is a set of extensions to the HTTP protocol which allows users to collaboratively edit and manage files on remote web servers.  AKA: DAV
