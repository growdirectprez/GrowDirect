Introduction

This collection is designed to give you access to information and resources that will help you deploy the Consumer Demand Signal Service within the Microsoft Supply Chain Orchestration Offering.

Introductory Topics

About this Resource Kit -- A description of the purpose and benefits of this kit.

How to Use this Resource Kit -- Tips on getting the most out of this kit.

About Microsoft Solutions Framework -- Information on the history and purpose of Microsoft Solutions Framework and its best practices.

Sections

Samples -- The sample documents are included to assist project teams create required documents during development.

Templates -- The templates are included to assist project teams track progress and produce deliverables.

Checklists -- The checklists are included to assist project teams perform tasks during the project.

Guides -- The informational guides will help the team perform tasks and create deliverables.

Tools -- The tools are software applications that can help with infrastructure deployment projects and resource kits.

Links -- Pointers to more information on the Web.
