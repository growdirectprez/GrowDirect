Systech: Retail Connector/4690 Tlog Fragmentizer

This program runs as a background application on the 4690 controller and processes the current Tlog (SA Tlog supported currently) to produce delta output files with a maximum size dictated by configuration.  The fragmentizer keeps track of where it read up to in the Tlog in a mirrored file so that it can run in the event of a controller failure.

The fragmentizer can produce binary fragment files or an XML version of the fragments.
