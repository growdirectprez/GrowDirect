Origins of XML:

XML, eXtensible Markup Language, is a subset of SGML or Standard Generalized Markup Language.  SGML was derived from GML or Generalized Markup Language.  GML was constructed by IBM in 1969 and was intended to be a meta-language.  Meta-languages are languages that describe other languages and the rules of that language.  XML was initiated by the W3C, World Wide Web Consortium in 1996 to consolidate SGML and HTML.  

For more information about XML see W3C

What is an XML Schema?

XML schemas provide a metadata framework for all possible valid documents.  XML schemas provide a set of rules, or constraints, that allow a sender and receiver to communicate data effectively.  These rules can be easily compared to grammar and spoken languages.  As people we have to follow a certain level of written and spoken rules in order to communicate properly.  If these rules are not followed the true meaning of what we are trying to communicate can get lost or misinterpreted.  XML schemas follow a similar set of guidelines and constraints.  These rules must be followed in order for the sender and the receiver to communicate.  

What is Well Formed XML?

Well Formed XML follows these rules:

Element names can only start with alpha-characters and underscores.  

Elements can only contain letters, numbers, hyphens, periods, and underscores.

All tags must use proper delimiters.  For Example: <Name>John</Name> is a well formed because the beginning tag <Name> is followed by and end tag </Name>.

Attribute values must be encapsulated with quotes.  For Example:  <myfile filename="myfile.txt"/>

The tag of an empty element must have a slash before its ending bracket.  For Example:  <Name/>

Elements cannot overlap.

Certain reserved characters cannot be contained in content.  For example <,>, and & cannot be used.  The following is not correct:  <GREATERTHAN>3 > 2<GREATERTHAN/>
