IBM 4690

TRANSACTION SUMMARY LOG RECORDS

Represents transactions delimited by a carriage return and line feed.  Strings that make up these records represent items and tenders delimited by commas.  Sub-strings that make up these strings represent amounts and flags delimited by colons.

Primarily Packed numeric format (occasionally ASCII) packed numeric format do not contain leading zeros and null if the value is zero (0)

TRANSACTION SUMMARY LOG CONTAINS THE FOLLOWING RECORD FORMATS:

00 Transaction Header
01 Item Entry
02 Item Entry Extension
03 Discount
04 Voided Discount
05 Tender
06 Tender correction
07 Tax
08 Tax refund
09 Food Stamp Change
10 Manager Override
11 Data Entry
12 Price Change
13 Till Change
14 Item Record Change
15 Trading Stamps
16 Reserved for EFT feature
17 Miscellaneous cash item tracking
20 Exception Log
21 Store Closing
30 Reserved for EFT feature
98 Operator Training
99 User exit

EVERY TRANSACTION RECORD begins with a transaction header string, except for the store closing and exception log records that contain only a single string. A user exit can also comprise a record by itself.

Please consult the IBM 4690 Users Manual for more record format details.
