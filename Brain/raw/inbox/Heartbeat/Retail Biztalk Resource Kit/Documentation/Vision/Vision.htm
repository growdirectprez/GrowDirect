Overview:

The Retail Biztalk Resource Kit (RBK) will provide a Retail framework for extracting, transforming, and serializing transaction log data.  The data source will be IBM 4690 Point of Sale transaction log data and  will use Biztalk to  transform this data into ActiveStore RBI schema found on http://www.Biztalk.org.  This RBK will provide the user an example of how to integrate IBM 4690 transaction log data with other products and services using Biztalk.  The RBK is intended to be in PILOT form to decide future Retail integration opportunities using Biztalk Server.

Retail Biztalk Resource Kit Vision:

“To compete in the fast-changing digital economy, retailers need solutions that create business agility—the ability to change direction quickly, easily, comprehensively, and profitably. Today's market dynamics demand that retailers maximize efficiency throughout the supply chain as well as the corporate enterprise, and provide managers with business-critical information on performance.”   From:  http://www.microsoft.com/business/industry/rethome.asp

Retailers are faced with a mountain of technical challenges ranging from physical implementations to software integration.  Many retailers have implemented many disparate systems to manage their business and are faced with tough questions in light of competitive strength and advantage.  Today’s retailer will make better-more informed decisions with data from many different systems, at near real time, as to form a collection or warehouse.  Retailers will be able to integrate this data into many different vendor systems that provide robust services such as loss prevention, promotion analysis, or OLAP.  The Biztalk SDK for Retail will provide Retailers and Microsoft development resources with a working example of software and system data integration.

The MCS Retail National Practice will develop this kit for worldwide publication in partnership with several partners and internal Microsoft organizations.  The solution will also act as a discovery process for determining real time versus batch data extraction and in-store or enterprise extraction.  This development effort will utilize Microsoft Solutions Framework. 

Scope:

The Retail Biztalk Resource Kit for will provide a framework for integration of IBM 4690 transaction log data into ActiveStore RBI Transaction XML schema definition found on:  http://www.Biztalk.org.  This release will not support other POS data sources.  The solution will also utilize software from Systech to transform the proprietary IBM 4690 format into XML.  Biztalk will be used to validate the XML and transform the data into ActiveStore RBI transaction log format.  The kit serves as an example framework and will act as a PILOT to determine future development requirements.

Future releases of this Kit could implement POS operating systems as data document sources.  Destinations,  could be participating vendors that provide specific business value to Retailers.  These vendors provide robust retail industry applications and hosted web services such as loss prevention, retail analysis, CPFR, or inventory management.  Future releases of this product could also utilize other vendors for transforming proprietary Point of Sale operating systems data.
