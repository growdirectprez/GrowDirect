# Ollie’s Secure Store Solution
Secure Store v5 is an Exception Based Reporting System designed to assist Loss Prevention and Store Operations in identifying anomalies at point of sale
The Secure application will receive daily batch feed of POS sales data, store and item master data, Employee reference data and an additional feed of returns data from the Ollie’s Refund management system
The secure application will retain twelve months of detailed transactional data to support Exception Base Reporting on sales data transactions for approximately 271 retail locations
Configuration of the base Appriss Retail Enterprise Case management application is also included in the scope of the project

# Project Planning
Analyze and Determine source for POS data - Determine the best approach to source your POS data that will drive the Secure application.
Identify additional data feeds that are in scope for the project
Establish frequency and volume of each data source
Complete a preliminary sizing analysis to estimate the amount of storage required and confirm the retention estimates
Determine Infrastructure needs and estimate the timeline for procurement and availability date.
The typical deployment timeline for a Secure Store engagement is 18 – 20 weeks from the technical kickoff.  With data mapping activities already underway, we will work with the Ollie’s team to develop the detailed project plan, identify roles and responsibilities , agree project dependencies and delivery milestones to keep the project on schedule.

# Client Services
Loss Prevention Strategy Sessions – Develop a full understanding of the LP structure, Establish the Risk Dictionary and strategize how Secure is going to be integrated into loss prevention processes.
Operational Review – Appriss Retail will run through a series Customer and Non Customer facing transaction sets to test System Functionality, Policy, and Procedure in the following areas:

Price Modifications
Refunds / returns / exchanges
Line Voids / error corrects
Post Voids
Transaction suspend / resume / cancel
Coupon / Other Discounts
No sales / Open Drawer events
Manager overrides / Policy
Velocity Controls / Limits

# Define Process & Develop the Risk Dictionary
A standard set of risk templates are evaluated with the Client Services team during offline strategy session to establish the starting point for the application configuration
The predefined Analyst & Investigator roles in the Secure application are configured for the Ollie’s application.
The operational workflow for Secure within your organization is explained.
Dashboards for each of the roles are reviewed.
Secure receipt view and data naming conventions are configured
Data Validation begins on the QA system with live data
The Enterprise Case management configuration is completed
User Training and Ongoing support is delivered by Client Services
Preliminary Instant Analytics are agreed and configured to begin delivering work items to the investigative flow.
