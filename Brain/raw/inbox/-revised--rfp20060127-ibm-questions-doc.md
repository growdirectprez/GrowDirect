IBM Questions Pertaining to PLCB RFP 20060127
May 2, 2006

Project Structure
Is there a preferred format for status reporting?
Is there a preferred project planning tool?
Infrastructure
Is there a specific platform that is to be used? (Are there any hardware or OS restrictions?)
Is remote access to legacy systems available?
Project Scope
Is this for alcoholic beverages only? (Accessories, gifts and non-alcoholic beverages excluded)
Has additional review of the completed merchandising test been performed, and, if so, is that data available?  Is the raw data from the test available to be used by the selected contractor?
Please clarify whether the PLCB has a preference for any tools to be used by the vendor.  In other words, does the PLCB have specific tools in mind that the vendors are required to use?  If a space planning, assortment planning, optimization software package is implemented and used, is the vendor responsible for purchasing the software?
For the delisting deliverable, is there a requirement to provide a recommendation of what to do with the delisted merchandise?
For the category right-sizing deliverable, is there a requirement to recommend an “end of life” strategy for the SKUs that did not survive the rationalization?
Are we required to maintain only the eight identified store clusters?
Can the team recommend reorganization of the store display categories as well as shelf optimization? (ie, add more space to the wood section, change the location of different spirits?)
Are endcaps and promotional racks considered “shelves?” Are they currently plan-o-grammed?
Will the quarterly reviews during the implementation be evaluated independently, or as a trend over time? (Early adoption/change vs. long term impact)?,Project Protocol
How are the resets of the plan-o-grams monitored?
Will vendor resources be required to visit the stores to ensure that the plan-o-grams have been set correctly?
External Dependencies
While the ERP project is in place and a new replenishment tool being implemented, what legacy forecasting/replenishment/demand planning tool is available?
Data Availability
What marketing/demographic data is available?  Was the data that was used for the first test a “one shot deal?”  Or is it available with current information?  In some cases, retailers store their own data in a data warehouse.  The data is continuously updated and available at any time to be used for continuing analytics.  We are seeking clarification to understand how current the data is updated or if the vendor will be required to pull the data as part of the effort.  In other words, is the data for the retail stores current, is the data updated on a frequent basis, and will the updates continue to be maintained throughout the lifecycle of this project?  Additionally, we were interested in whether PLCB maintains buyer demographics either in-house or purchased from a third party.  Buyer demographics might include age, ethnicity or income of the person who made the purchase, as well as whether the purchase was via cash/Debit or credit.

How frequently is data updated?  (Sales, inventory, demand forecasts, replenishment orders, etc)  We are seeking clarification about PLCB’s "batch schedule" and how often the data is refreshed for analytical use.  In the PLCB’s legacy data sources, i.e., for sales, inventory, demand forecasting, replenishment, etc., how often is data updated?  As an example, when a Buyer gets a report or uses an application to obtain sales data, is that data from yesterday?  Last Saturday?  Last hour?  Etc.


Other Questions
Do all stores within a store cluster have the same number of shelves that are the same length, height and depth?  Do they have the same (or similar) square footage?  Are there general guidelines for the number of entries, the placement of the cash registers, wood fixtures, etc?
