BroadVision Technical Support

Technical Support services are provided on an annual basis to BroadVision customers. A standard
90-day warranty is also provided with all software.

If you experience problems using BroadVision software products, contact the BroadVision World-
wide Customer Support Organization for assistance. Registered customers who have login names
and passwords can report problems via the BroadVision Web site at www.broadvision.com.

On the Web site, you can use the Problem Reports pages to access support-related technical
information, report problems, and track report status and responses. Telephone contact information
for BroadVision Customer Support is also provided on the site. Contact your BroadVision Account
Representative to request a login name and password.

The Web site is the preferred method of reporting problems. When necessary, you can also report
problems via e-mail at bvhelp@broadvision.com. If you do so, be sure to include the case ID.

Support for Third-Party Software Products

To allow for complete testing, BroadVision certiﬁes BroadVision® One-To-One™ products for the
versions of third-party products that are released and available sufﬁciently in advance of the
BroadVision software release date. This often means that third-party vendors release new versions
of their products prior to the next release of the BroadVision software. While BroadVision would
prefer that customers use the tested and certiﬁed software versions, we also understand that
customers occasionally want to use the newer versions of third-party products. As long as the
vendor guarantees forward compatibility, One-To-One products should also work on the newer
versions.

BroadVision usually tests and certiﬁes these new versions of third-party products in the next
product release. This can be a good indicator that the newer versions work with the previous
release. In exceptional cases BroadVision may determine that the newer version of a third-party
product cannot be used because it fails in some way during the testing cycle. In this case we
continue to certify the older version.

BroadVision supports customers who use newer versions of third-party products by working with
the customer to resolve compatibility problems with the third-party vendor. BroadVision also
considers, at our option, developing and releasing minor ﬁxes for our products to resolve problems
with new versions of third-party products.

System and software requirements

Installing and using the One-To-One Design Center for Dreamweaver 2 has the same requirements
as your Dreamweaver 2 application:

l A PC running Windows 95 or Windows NT Version 4.0.

l TCP/IP networking.

l 15-20 megabytes of available disk space on the hard drive.

l 32 megabytes of RAM.

l A VGA monitor with a screen resolution of 800 x 600 or higher, and a color depth of at least 16

bits (65, 536 colors).

Installing Macromedia Dreamweaver 2

When you install Dreamweaver 2, you need the serial number for the product. This serial is located
in the upper right corner of the back cover of the Dreamweaver 2:Using Dreamweaver manual
included with the product.

To install Dreamweaver 2:

1. From the Design Center for Dreamweaver 2 CD, run setup.exe from the

windows\macromedia directory.

2. Follow the instructions on your screen.

Installing Design Center for Dreamweaver 2

To install the Design Center for Dreamweaver 2:

1. From the Design Center for Dreamweaver 2 CD, or from the One-To-One software on your

network, run setup.exe from the windows\design directory.

2. Follow the instructions on your screen. The installation program detects the location of the

Macromedia Dreamweaver 2 installation and installs the Design Center for Dreamweaver 2 ﬁles
in the correct Dreamweaver 2 folders.

Installing the Design Center server extensions

The Design Center for Dreamweaver 2 server extensions must be installed in the script root of your
One-To-One Interaction Manager. The script root is deﬁned in the conﬁguration ﬁle for the
Interaction Manager.

To install the Design Center for Dreamweaver 2 server extensions:

On Windows NT

Copy the dw_server directory from one of two locations to your script root:

l The windows\design directory on the Design Center for Dreamweaver 2 CD-ROM

l The Macromedia\Dreamweaver 2 directory on your machine.

When you install Design Center for Dreamweaver 2, the installation program copies the server
extensions directory, dw_server, to the Dreamweaver directory.

On UNIX

Copy the dw_server directory from the windows\design directory on the Design Center for
Dreamweaver 2 CD-ROM to your script root.

l 08392: If you enter a duplicate variable name or fail to enter a variable name in the ﬁrst dialog
when running a Data Access Script command, the system does not display an error message
until you click Finish or Next in the last dialog of the wizard.
Work Around: Click the Back button to return to the ﬁrst wizard dialog. Enter a variable name
that is not a duplicate of an existing variable name in the document.

l 08456:Using the Dreamweaver 2 Commands|Apply Source Formatting command may result in

code that cannot be interpreted by the Interaction Manager.
Work Around: Do not use this command with Design Center for Dreamweaver 2 ﬁles.

l 08476: If you run the Hyperlink to|Generic JSP Page command and enter a ﬁle name with
embedded spaces, the link does not work correctly on Netscape 3.04 and 4.5 on Microsoft
Windows.
Work Around: Do not use ﬁlenames with embedded spaces.

l 08569: When BroadVision JavaScript is added to a Dreamweaver document, the BroadVision
script variables, such as <%= dwMVExternal.INTEREST_RATE %>, are displayed in the
document window instead of ASP icons. The Dreamweaver window is not supposed to display
any BroadVision server-side JavaScript, and it is not possible to resize the table cells to any
width narrower than the script variable either by using the properties inspector or dragging on
the cell border with the mouse.
Work Around:To display the document window with ASP icons instead of script variables,
which allows you to resize the window: make a change in the Dreamweaver document window
and undo the change in the HTML inspector.

l 08610: If you select the Finish button before the last screen in a wizard, the application displays
an error message that lists any missing information. If you haven’t yet reached the screen where
that information would be selected or entered, this message can be confusing.
Work Around: Always click the Next button when you complete a dialog. In the last dialog of a
wizard, Next has the same function as Finish. The appearance of the Finish button in all wizard
dialogs is a limitation of Dreamweaver 2.

l 08631: The Transform HTML to Script command does not display the selected HTML blocks

correctly in the Static HTML Elements list. If you select a subset of multiple items in <p> tags,
the application displays all static HTML elements on the page. If you select all cells in a table,
the application displays all static HTML elements on the page. If you select a subset of the cells
in a table, the application displays only the contents of the ﬁrst table cell.
Work Around: Transform one static HTML element at a time when working with less easily
identiﬁed elements such as images. Otherwise, select an entire table or multiple non-table
elements outside a table to transform multiple elements.

l 08653: If you run BVI_Category|Data Access Script and use double quotes ("), ampersands (&),
or plus (+) or equals (=) signs in the selected category, Design Center for Dreamweaver 2 does
not generate the correct code. The category name may be truncated or otherwise encoded
incorrectly. This error also applies to rules sets used when running BVI_ContentList|Data
Access Script.

l 08698: External proﬁle attributes, such as ACCOUNT_NAME and ACCOUNT_STATUS in the
Broadway application, are not under the control of One-To-One. Updating these attributes may
not always be possible.
Work Around: Do not select “Account Name” or “Account Status” in the BVI_Visitor|HTML
Form wizard.

l 08916: If you select the Use Small Font Sizes option when you run the BVI_Category|HTML
Table Display or BVI_Content|HTML Table Display command, the application ignores the
selected option and enters the cell text using the default font size.
Work Around: Highlight each cell value and change the size attributes in the Property inspector.
Display the Property inspector with the Window|Properties command.

l 08918: If you run BroadVision Tags|Add and select the Import Current Selection option for
selected text that is before the <body> tag, the import fails with a series of error messages.
Work Around: Do not select the Import Current Selection option when running the BroadVision
Tags|Add command.
