Process Name Site Management (Level 2)
Objectives
To provide a framework to support accurate and efficient site-level assortment management, space planning, allocation, distribution, replenishment, and reporting.

Critical Success Factors
Ability to provide complete and meaningful site information for merchandising, finance, and warehouse functions.

Ability to consolidate site information into meaningful hierarchies.

Ability to create/modify store maps based on new store maps and footage changes.

Ability to efficiently support assortment, allocation, and replenishment decision-making.

Assumptions
A site is defined as stores, warehouses, mixing centers, customers, consumers and SSG.

Assortment Management has been assigned the responsibility of developing and maintaining assortment modules.

Price Management has been assigned the responsibility of developing pricing requirements for new stores.

Replenishment parameters to come from Replenishment process.

Any return can be accepted at any Store which will be controlled by an item file that has an entire listing of articles.    (12/04/97)

Manage Site Maps process will be moved/become part of New Store/Remodels process.  (12/11/97)

Creation and Management of DC Maps used by EXE/Warehouse Management System is considered to be a DC function and considered to be Out of Scope for this process.  As  used in this document, the ‘Manage Site Maps’ process refers only to Stores (and not to DCs)  (12/18/97).  

The projected Store Remodels target process  is essentially the same as the Set Up New Site level 3 (maintain site) process contained in this document.  New Site/Store Remodel requirements will not modeled separately, and will be rolled up into the Set Up New Site level 3 process contained in this document.  (12/18/97)

Forecasting parameters come from the forecasting process.

New Store Planning will come from Financial / Merchandise Planning.

Operational calendars/process will continue to be maintained at the department level and will be external to SAP.

Market Managers and Regional Vice Presidents will have input into the Manage Site Map process.  (1/19/98)

That the first step in the Manage Site Maps process - Review Performance Statistics by Category - also includes comparison of stores geographically or by other similar reference.   An example would be the usage of characteristic values of store type assigned to each store.  This information can then be used to compare and manage site maps of like stores.  (1/22/98)

For requirements definition purposes, a PETsMART Planogram ID will be represented as Layout Module in SAP. (Added 1/24/98)

Manage Site Maps (Level 3)
Requirements
General  Merchandise Presentation/Planogram Management requirements start with working with Architects in defining layout of a new store/remodel.  Process requirements include:
Real Estate feeding in floor maps.
[Considered External to SAP]
Based on the square foot dimensions on the maps - and the core mix of products for the store - create a rough layout or footprint for the store.
The footprint will identify how the specialties/major merchandise categories will look (e.g. Dog Ties 16’, etc.). 
Specific articles are  NOT added to the footprints.
Creation of the store footprint also includes the evaluation sales performance of like sites with similar maps.
Assign existing and/or  generate new  Planogram Ids as required; Each ID includes the following attributes:
Department (‘Dog’ )
Category (‘Toys’)
Display Version (‘00’)
Square Footage (16’)




The capability to query a database of Planogram Ids to determine which stores carry which Planogram (or fixtures) is required to support this process. Also required is the capability to: 
Tie multiple Planogram IDs to a single site.
Allow multiple sites to tie to the same Planogram ID. 
[Planogram Requirements met assuming PETsMART Planogram IDs are equivalent to  SAP Layout  Module. - See Assumptions.]
Also required is need to determine the sales impact of increasing or decreasing the square footage assigned to a [by] product category.  (e.g. what is sales impact of taking 10% of space away from Dog and giving it to Cat, etc.)

The system must report the following information for site map creation/maintenance:
Site number
Address
Region
Open date
Planogram IDs
Layout attribute codes (State Line Tack, Vet Services, Aquatic, Equine, Grooming, Three Dog Bakery)
Square footage



Performance Measures
Performance Measures for Mange Site Maps need to include Store level comparisons of GMROI by Square Footage, Merchandise Category and Planogram ID.  (12/18/97)



Set Up New Site  (Level 3)
Requirements
Organizational Structures related requirements start with PETsMART defining what type of sites it will set up.  Site types needed include:
Store Support Group (SSG)
Distribution Centers (DCs), including Fish DCs
Mixing Centers
Store

Model Stores are expected to be used in the Set Up New Site process to complete new store - forecasting, ordering and replenishment related tasks.  Model Site and Site Copy related requirements include:
Copy assortments or articles to a new store including:
Assigning a SKU list based on like-store by any combination of merchandise category, store layout, and range grade.
Copy the pricing strategy from a “like” store in terms of product mix and volume (minus promotional pricing)
Tie assortment modules to a Planogram (through an assortment layout listing).

Tie a Planogram to replenishment. For example, the requirement is the ability to identify and set article and site replenishment parameters during the Planogram generation process.  If a planogram (layout module) is added or changed on a site master then this should trigger potential article/site replenishment parameter setup or changes.
Copy Forecasting and Replenishment parameters set up for an existing or model store to a new store. 
Provide capability to assign Replenishment/DC Sources to the site.   Retailers need the ability to assign a primary source of supply and additional sources based on inventory.  For example, an west coast DC is the primary source of supply, however if the west coast DC is out of stock then check the midwestern DC.  If all of the internal DC's do not have inventory then source externally with the vendor.
