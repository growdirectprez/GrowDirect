3.3.2 Product Integration

Please describe the integration capability of your solution with external applications.  What features of your solution make it a good fit in a multi-application environment?


Retek Integration Solution 

The Retek Integration Solution (RIS) combines message-based integration and monitoring with the Retek Integration Bus (RIB) EAI solution; multi-threaded data extraction, transformation and low-level data loading capabilities with the Retek Extract Transform and Load (RETL) product and other point-to-point solutions providing data as needed by Retek and third-party applications supporting industry-standard formats.  RIS delivers all the benefits of an integrated footprint with enterprise wide visibility that retailers demand.
 
Retek Integration Bus (RIB) 

The RIB provides near real-time publication and subscription message-based integration.  The Retek Integration Bus (RIB) is an information management application that delivers a set of common business objects and documents used for messaging communication to/from the Retek Merchandise System (RMS).  Instead of integrating each application with every other application, all applications may now be integrated via the RIB.  The RIB reduces implementation time and cost by providing easier integration with legacy and third-party applications.  Development, maintenance and upgrade are faster and cheaper because the resulting environment is standardized and comprehensive.  Business functions are exposed at a granular level for each integration point and standard messages are represented in a flexible tagged (XML) format that when modified, impact a small set of functions.  Subscribing applications may pick and choose the elements of a message that are needed for processing.  Redundant integration points are eliminated and status / feedback messages are implemented to report of success and failure on common business transactions and improve data management.  The RIB’s modular architecture enables retailers to maximize their investment in legacy systems while implementing the Retek modules that provide high-impact returns.  The RIB has been developed using the technology foundation provided by SeeBeyond’s e*Gate products.

Retek Extract Transform and Load (RETL)

Scheduled high-volume, multi-threaded data extraction, transformation and data loading capabilities are found within the Retek Extract Transform Load (RETL) product.  The RETL is a high-performance runtime product specifically designed for use in parallel processing systems where high volumes of data must be processed quickly.  By incorporating RETL into an application, the time required to process data from databases and flat files may be reduced.  By adding server processors, the RETL can scale to handle even larger volumes of data.  The RETL is targeted toward two primary uses: 

Data extraction and loading for interfacing between Retek applications and / or legacy systems; 
Batch processing of computations, such as pre-aggregating data for reporting applications, or calculating replenishment numbers for merchandising applications.

4.1.18 Transaction Recovery

Please provide any details you may have regarding available transaction recovery capabilities, i.e. rollback to point of failure, redundancy etc.


Retek has build Restart and Recovery into the software architecture which handles recovery capabilities.  The restart capabilities will revolve around a program’s logical unit of work (LUW).  A batch program will process transactions and commit points will be enabled based on the LUW.   LUWs will consist of a relatively unique transaction key (such as sku/store) and a maximum commit counter.  Commit events will take place after the number of processed transaction keys meets or exceeds the maximum commit counter, e.g. every 10,000 sku/store combinations a commit will occur.   At the time of the commit, key data information that is necessary for restart is stored in the restart tables.  In the event of a handled or un-handled exception, transactions will be rolled back to the last commit point, and upon restart the key information will be retrieved from the tables so that processing can continue from the last commit point.

Retek security should be business driven. It is for this reason that Retek allows for customization within Retek applications for various security capabilities. The process for setting up Retek application security involves identifying the tasks each user or group of users needs to perform, as well as the database privileges these users need to perform the tasks. Supervision Hierarchy

Parameter Driven Groups

Retek defines security at Database, Application and Data levels.  
Database-level security involves setting up user roles with specific privileges to tables (such as the ability to insert, update, select, and delete from specific tables).  The next step is to grant each user the necessary user roles.

The application-level security provides access to various dialogs, menu options, and actions (such as new, view, edit capabilities) according to the user roles.  For example, a ‘Supervisor’ user role may have full order approval privileges; however, a ‘Clerk’ user role may only have the ability to create new orders and modify existing orders.

The data-level security provides access to specific data elements within various dialogs.  This security feature provides a method for protecting product, location, and price zone records. The users within the groups share the same permissions to view, add, edit, and delete records in specified functional areas.  For example, a buyer in a particular department should only be able to create purchase orders with products in their department and should only be allowed to order them to particular locations.  A store user should only have access to transfers involving their store.

6.2 Additional Systems Capabilities

Please comment briefly on your ability to provide functionality not specified in the requirements described in this RFP. (e.g. data collection, customer data confidentiality, warehouse management, etc) 


The Retek solution suite comprises over 30 applications, 14 of which are being proposed to Katz.

Here are six additional solution areas that can deliver results for Katz as its requirements evolve.

Warehouse / Distribution Center Replenishment

The Retek Merchandising System being proposed to Katz also includes substantial functionality for warehouse / distribution center replenishment.  Thus, within one application, Katz can obtain true visibility to perpetual inventory across its organization from warehouses through stores.

Likewise, the Retek Merchandising System provides one master of warehoused, DSD, and vendor to store product.


Merchandise Planning / Category Management

Retek is proposing Retek TopPlan that provides highly flexible financial, product, and location planning with the ability to fully reconcile and approve plans; Retek Demand Forecasting and Promotional Forecasting that provides highly accurate forecasts for supply chain planning, allocation, and replenishment; Retek Assortment and Space Optimization that delivers macro-level category planning for the retail stores; and Retek Visual Space Planning that enables a retailer to visualize merchandise assortments in a three-dimensional environment and optimize use of space.

To extend this category management solution set, Retek offers Retek Assort a solution that plans product assortments consistent with overall financial plans (TopPlan) as well as space constraints; and Retek KeyPlan that provides item-level planning capabilities to produce a bottom up plan is conjunction with the overall financial plan.


Retek Price Optimization

Offered as a service, Retek Price Optimization delivers optimized pricing recommendations on a weekly basis among regular retail (performance), promotional, loyalty, and / or clearance prices.

Retek has at its disposal, a wide range of modeling techniques to assist in delivery optimized prices.  

Elasticity models typically drive an equation that shows the relationship between price and demand.  Retek uses elasticity modeling in conjunction with the promotional models, and will augment it with price point pricing.  Cross-elasticity is a component of the interaction between items.  Halo, cannibalization, and pantry loading relationships are modeled at the item level and can be forecasted.


RPOS – Retek Point of Service

RPOS is a robust, Java POS solution that has been proven in the market.  The solution is designed to improve the performance and efficiency of in-store systems – more localized and flexible retail decisions through its unique “thin client” architecture means faster, better and more flexible customer-facing services. RPOS enables improved data movement and inventory/labor cost management at the store-level.

RPOS is built on adaptable technology, enabling it to run in a traditional point-of-sale configuration with the data and processing residing in the stores or deployed in a true hosted/thin client manner, using low amounts of flash memory on a scaled down PC.  RPOS is operating system and hardware-independent, running on Windows NT/9x/2000 ME, Linux and IBM, NCR or Sun hardware.  Further, it enables mobile device availability delivered on Palm OS and any portable PC OS that supports Java.


Retek Inventory Optimization

Retek Inventory Optimization uses actual client data to model and simulate their replenishment environment. Using this modeling, first “Quick Wins” and later, optimal replenishment strategies are identified, taking into account the retailers specific business drivers.

These optimal replenishment strategies recommended by Retek Inventory Optimization may include reconfiguration of Retek’s Merchandising System (RMS) replenishment parameters or amendments to the clients’ legacy replenishment processes.

The Inventory Optimization module is then configured to apply and monitor the client-specific optimal replenishment strategies at the item/location level. It updates the RMS replenishment parameters as required to reflect behavior changes at the item/location level.

The Inventory Optimization module is deployed at the client site as part of the services offering. The module is not available without the completion of the Optimization and Simulation analysis done by the Retek Consulting Team at Retek’s offices. 

This micro-management of the client’s replenishment environment ensures accurate replenishment and allows the user to concentrate on maximizing profit, rather than the time‑consuming business of managing replenishment details.


Retek Distribution Management

Retek Distribution Management (RDM) is a warehouse management system that provides all the tools necessary to efficiently manage and control a complex
distribution center.  Leveraging a process-based application framework, RDM provides the functional flexibility and timely, accurate information necessary to consistently manage and improve distribution operations.  The results are improved service levels, reduced inventory and lead-times, increased productivity and reduced labor costs.   Further enhancing the advanced functionality of RDM are the labor management and operations management modules.  Retek® Labor and Operations Management™ (RLM) provides users with the capability to consistently improve labor productivity, reduce labor costs and improve equipment and facility utilization by presenting the user with critical performance information and analytics required to manage and optimize distribution operations.
