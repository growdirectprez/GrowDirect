# OwnPalosVerdes.com

## Deploy to Vercel (one command)

```bash
npx vercel deploy --yes
```

Or connect this folder to Vercel via GitHub for auto-deploys.

## Files
- `index.html` — Main site (Angelique Lyle homepage)  
- `schools.html` — PVPUSD School Guide (SEO pillar page)

## Custom domain
After deploying, add OwnPalosVerdes.com as a custom domain in Vercel dashboard:
Settings → Domains → Add → ownpalosverdes.com
