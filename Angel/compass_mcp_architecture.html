MCP Service Layer

Nine Core MCP Services

Each MCP server exposes a set of tools that Claude (or any AI agent) can call. Think of these as the building blocks — the agents above compose them into workflows.

compass-crm

MCP Server
  • search_contacts — Find contacts by name, tag, or Collection
  • create_contact — Add new lead with tags, source, notes
  • update_contact — Edit tags, notes, status, pipeline stage
  • get_collections — List all Collections
  • add_to_collection — Drop a contact into a Collection
  • get_likely_to_sell — Pull Likely to Sell scores for an address/area
  • log_activity — Record a call, meeting, or note
  • get_pipeline — View deal pipeline with stages + values

compass-listings

MCP Server
  • search_listings — Search Compass listings by area, price, features
  • get_listing — Full listing detail (photos, description, history)
  • create_coming_soon — Set up a Coming Soon / Private Exclusive
  • get_showing_requests — View pending showing requests
  • run_cma — Generate a Comparative Market Analysis
  • get_market_stats — Area-level market data (DOM, prices, inventory)

mls-search

Data Connector
  • search_mls — Query CRMLS (SoCal MLS) with full filter set
  • get_property_history — All historical sales, price changes, listings
  • get_comps — Find comparable sales within radius + timeframe
  • get_tax_records — County assessor data, lot size, year built
  • monitor_new_listings — Real-time alerts for matching criteria

property-intel

Data Connector
  • attom_property_detail — ATTOM comprehensive property data
  • attom_avm — Automated Valuation Model estimate
  • smartzip_score — Predictive seller likelihood score
  • owner_lookup — Current owner info from public records
  • permit_history — Building permits pulled on the property
  • natural_hazard — Fire zone, flood zone, earthquake fault data

compass-marketing

MCP Server
  • create_campaign — Build an email campaign from template
  • send_email — Send to contact or segment
  • get_templates — List Marketing Center templates
  • create_collection_share — Generate a shareable Collections link
  • get_campaign_stats — Opens, clicks, responses

school-data

Data Connector
  • get_schools_by_address — Schools assigned to a property
  • get_school_ratings — GreatSchools + Niche + state test scores
  • get_feeder_pattern — Elementary → Middle → High school path
  • compare_schools — Side-by-side comparison matrix
  • get_district_boundary — PVPUSD and neighboring district maps

doc-gen

Skill
  • generate_listing_presentation — Branded CMA + listing pitch deck
  • generate_buyer_guide — Custom buyer guide for a specific family
  • generate_market_report — Monthly neighborhood market report
  • generate_offer_letter — Buyer offer cover letter
  • generate_disclosure_summary — Plain-English disclosure digest

email-sms

MCP Server
  • send_email — Gmail/Outlook send with templates
  • send_sms — Twilio text to contact
  • search_inbox — Find emails from a contact or about a property
  • draft_reply — Draft a response to an email thread
  • schedule_followup — Set a timed follow-up message
AI Agent Layer

Five Autonomous Agents

These aren't just chatbots — they're autonomous workflows that compose multiple MCP tools to complete complex tasks end-to-end. Each one replaces or augments a team member.

🏗️ Transaction Coordinator Agent

Replaces: $500–1,500/transaction TC hire
Offer accepted → Open escrow → Track contingencies → Manage deadlines → Coordinate close
What it does: The moment an offer is accepted, this agent creates the transaction timeline, calculates every contingency deadline (inspection, appraisal, loan, closing), sends reminders to all parties (escrow, lender, inspector, buyer/seller), tracks document status, and flags anything at risk of going late. It reads incoming emails about the transaction and updates status automatically.

Tools it uses: compass-crm (update deal stage), email-sms (send reminders, read updates), calendar (set deadlines), doc-gen (generate status reports)

Angelique's role: Reviews the daily status digest, handles relationship calls, makes judgment decisions. The agent handles all the chasing, tracking, and deadline math.

🎯 Prospecting Agent

Replaces: ISA (Inside Sales Agent) — $3,000–5,000/mo
Identify targets → Enrich data → Score & prioritize → Draft outreach → Warm handoff
What it does: Runs daily. Pulls new Likely to Sell scores from Compass, cross-references with SmartZip predictive data and ATTOM ownership length, scores each prospect, drafts personalized outreach (mentioning their specific neighborhood, school proximity, recent comps), and queues it for Angelique's review. Also monitors the "relocating mom" content leads from OwnPalosVerdes.com and prioritizes based on engagement.

Tools it uses: compass-crm (Likely to Sell, contacts), property-intel (ATTOM, SmartZip), mls-search (comps for outreach), school-data (personalize for families), email-sms (draft + send)

Angelique's role: Reviews the daily "hot list" (5–10 minutes), approves/edits outreach, makes the personal calls to top-scored leads.

✍️ Content Engine Agent

Replaces: Content writer + social manager — $2,000–4,000/mo
Monitor trends → Generate content → SEO optimize → Schedule & publish → Track performance
What it does: Pulls real market data weekly (new listings, price changes, sold comps), generates blog posts, Instagram captions, email newsletter content, and market update videos scripts. All content uses real numbers, not fluff. Optimizes for the long-tail SEO keywords we identified. Schedules posts across platforms.

Tools it uses: mls-search (real market data), property-intel (ATTOM trends), school-data (school content), compass-marketing (email campaigns), doc-gen (reports, guides)

Angelique's role: Reviews weekly content batch (15 minutes), adds personal voice / anecdotes, approves for publish.

📊 Market Analyst Agent

Replaces: Manual CMA prep — 2–3 hours per listing appointment
Receive address → Pull all data → Analyze comps → Generate CMA → Branded presentation
What it does: Give it an address and it does everything: pulls property details from ATTOM, finds 10–15 comparable sales from MLS, adjusts for square footage / lot size / condition / view, calculates a price range, generates a branded CMA presentation with Angelique's branding, includes neighborhood stats and school data. Ready for a listing appointment in under 5 minutes instead of 3 hours.

Tools it uses: mls-search (comps, history), property-intel (ATTOM, AVM, tax), compass-listings (Compass CMA), school-data, doc-gen (branded CMA deck)

Angelique's role: Reviews the CMA, adjusts based on her local knowledge (view premium, street appeal, etc.), presents to client.

🚀 Listing Launch Agent

Replaces: 4–6 hours of manual marketing setup per listing
New listing signed → Generate all assets → MLS entry → Marketing blast → Social campaign
What it does: When a new listing is signed, this agent creates: the MLS description (pulling from property data + neighborhood + schools), social media posts for Instagram/Facebook, a "Just Listed" email to her sphere, a Coming Soon campaign in Compass, a single-property website, and open house collateral. All from the listing photos and property data — no manual copywriting.

Tools it uses: compass-listings (create Coming Soon, MLS prep), compass-marketing (email blast), property-intel (property details), school-data (school proximity), doc-gen (flyers, brochures), email-sms (sphere notification)

Angelique's role: Provides photos, reviews all copy, hits "go."

Transaction Coordinator Agent — Full Workflow

This is the agent you asked about. Here's exactly what it manages, how it tracks deadlines, and what Angelique's daily interaction looks like.

What a TC Agent Manages Per Transaction

PhaseTasks the Agent HandlesDeadline Logic
Offer → Acceptance Track offer status, counter-offer timelines, multi-offer coordination, earnest money deposit tracking Response deadlines from offer terms
Opening Escrow Send executed contract to escrow, confirm receipt, track EMD delivery, distribute contact sheet to all parties 3 business days from acceptance (typical CA)
Inspection Period Schedule inspections (general, termite, sewer, roof), track reports, manage repair requests, monitor contingency removal deadline 17 days default (CA RPA), or per contract
Appraisal Confirm lender ordered appraisal, track completion, flag if value comes in low, coordinate response 17 days (loan contingency)
Loan Approval Track loan milestones (application, processing, underwriting, conditions, clear-to-close), flag delays 21 days (loan contingency)
Disclosures Track seller disclosures sent/received, TDS, SPQ, NHD report, HOA docs if applicable 7 days from acceptance (seller), 17 days (buyer review)
Pre-Close Final walkthrough scheduling, confirm clear-to-close from lender, coordinate signing appointment, verify utilities transfer 5 days before close
Closing Confirm recording, send "Congratulations" communication, trigger past-client nurture sequence in CRM, request review Closing date from contract

The Build Question

What Exists vs. What We'd Build

ComponentStatusPath to Build
Compass CRM MCP ❌ Doesn't exist Compass has no public API. Would need to use Zapier webhooks as a proxy, or browser automation (Claude in Chrome) to interact with Compass directly. This is the biggest gap.
MLS Search 🟡 Partial RETS/RESO Web API access requires MLS board membership + data license ($). Could proxy through Redfin/Zillow APIs for basic search, or use Compass's own search via browser automation.
ATTOM Property Data ✅ API available ATTOM has a REST API ($95+/mo). Straightforward to wrap as an MCP server. This is the easiest piece to build.
School Data ✅ APIs available GreatSchools API + Niche data + CA Department of Education public data. Could build a composite MCP server.
Document Generation ✅ We have this now We already built this — the PPTX, DOCX, HTML skills are the foundation. CMA decks, market reports, listing presentations.
Email/SMS ✅ MCP available Gmail MCP exists. Twilio for SMS is straightforward. Mailchimp API for sequences.
Transaction Coordinator 🟡 Skill + automation Build as a Claude skill + scheduled task. Reads email threads for transaction updates, maintains a deadline tracker, sends daily digests. The hardest part is parsing incoming emails accurately.
Content Engine ✅ Mostly built We already have the school guide, neighborhood content, and brand system. Add a scheduled task to pull fresh MLS data and generate weekly content batches.

The honest assessment: The biggest blocker is Compass itself — no public API means we can't programmatically create contacts, read Likely to Sell data, or manage Collections without either (a) Zapier as a proxy, (b) browser automation, or (c) Compass eventually building MCP support. Everything else — property data, school data, document generation, email — is buildable today.
