Step 2

Form Backend: Where Submissions Go

Option A: Formspree (Recommended to Start)

Zero backend code. Add a Formspree endpoint to each HTML form, and submissions go to Formspree's dashboard + trigger Zapier webhooks. Takes 15 minutes to set up.

ProsCons
No code changes to Vercel deploy50 submissions/mo on free tier
Built-in spam filtering (reCAPTCHA)$8/mo for 100 submissions
Direct Zapier integrationLess control over validation
Email notifications built inThird-party dependency

Option B: Vercel Serverless Functions (Later)

Custom API routes on OwnPalosVerdes.com itself. More control — validate data, enrich with ATTOM API, send to multiple destinations. Build this once you outgrow Formspree.

ProsCons
Full control over data processingRequires Node.js code
Can enrich leads before CRM (ATTOM)You maintain the code
No per-submission costsNeed custom spam protection
Can write to multiple systems simultaneouslyMore complex setup

Our recommendation: Start with Formspree for immediate lead capture (today). Migrate to Vercel serverless functions when you add ATTOM data enrichment or exceed 100 leads/month — a good problem to have.

Step 3

Zapier Automation Configurations

Each form type needs its own Zap with specific triggers, actions, and CRM tags. Here are the four Zaps you need:

Zap 1: General Contact → Compass CRM

⚡ Formspree → New Submission → 📧 Gmail → Send Email to Angelique → 📋 Compass → Create Contact
Trigger: Formspree submission where form = "contact"
Action 1: Email Angelique immediately (angelique.lyle@compass.com) with name, phone, message
Action 2: Create contact in Compass CRM → Tag: "Website Lead" + "General Inquiry"
Action 3: Add to Compass Collection: "New Leads — This Week"

Zap 2: Welcome Guide Download → Relocation Nurture

⚡ Formspree → New Submission → 📋 Compass → Create Contact → 📧 Mailchimp → Add to Sequence
Trigger: Formspree submission where form = "welcome-guide"
Action 1: Create contact in Compass → Tags: "Relocating Family", "Welcome Guide Download", source city from form
Action 2: Add to Mailchimp/Compass Marketing → "Relocation Nurture Sequence" (7-email drip over 6 weeks)
Action 3: Send Welcome Guide PDF via email immediately
Priority: 🔴 High — these are your hottest leads

Zap 3: Home Valuation → Seller Pipeline

⚡ Formspree → New Submission → 📋 Compass → Create Contact → 🏠 Compass → Likely to Sell Check
Trigger: Formspree submission where form = "valuation"
Action 1: Create contact in Compass → Tags: "Seller Lead", "Valuation Request"

Action 4: Add to Compass Collection: "Active Seller Leads"

Zap 4: Newsletter/Content Subscriber → Long Nurture

Step 4

Data Mapping: Form Fields → Compass CRM

Form Field Compass CRM Field Notes
Full Name Contact → First Name / Last Name Split on space in Zapier
Email Contact → Email Primary identifier — deduplicates
Phone Contact → Phone Optional on most forms
Message / Notes Contact → Notes Append, don't overwrite
"Moving from" City Contact → Tags + Notes Tag: "From: Austin" etc.
Property Address Contact → Notes + Collection For valuation requests
Form Source (hidden field) Contact → Tags "Source: OwnPalosVerdes"
UTM Parameters (hidden) Contact → Notes Tracks which content/ad drove the lead

Hidden fields matter. Every form should include hidden fields for form_source (which page), utm_source, utm_medium, and utm_campaign. This is how you know which content is actually generating leads — the school guide? A Facebook ad? The relocation article from Austin? Without this, you're flying blind.

Implementation

What the Form Code Looks Like

HTML Form → Formspree Endpoint

This is the actual code change needed on OwnPalosVerdes.com. Each form points to a unique Formspree endpoint.

<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">

  <!-- Visible fields -->
  <input type="text" name="name" placeholder="Full Name" required>
  <input type="email" name="email" placeholder="Email" required>
  <input type="tel" name="phone" placeholder="Phone (optional)">
  <textarea name="message" placeholder="How can I help?"></textarea>

  <!-- Hidden fields for tracking -->
  <input type="hidden" name="form_source" value="contact">
  <input type="hidden" name="page_url" id="page-url">
  <input type="hidden" name="utm_source" id="utm-source">
  <input type="hidden" name="utm_medium" id="utm-medium">
  <input type="hidden" name="utm_campaign" id="utm-campaign">

  <!-- Honeypot spam trap -->
  <input type="text" name="_gotcha" style="display:none">

  <button type="submit">Send Message</button>
</form>

<script>
  // Auto-fill hidden fields from URL parameters
  const params = new URLSearchParams(window.location.search);
  document.getElementById('page-url').value = window.location.href;
  document.getElementById('utm-source').value = params.get('utm_source') || '';
  document.getElementById('utm-medium').value = params.get('utm_medium') || '';
  document.getElementById('utm-campaign').value = params.get('utm_campaign') || '';
</script>
