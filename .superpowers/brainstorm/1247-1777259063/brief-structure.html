Design Module brief — structure

One .md file. Feed it to Claude.ai Design Module to generate the site. Each section tells Claude what to build and what content to use.

Block 1 — Context + audience

Who reads this site. What they already know. What they need to walk away believing. Keeps Claude.ai from generating generic copy.

Block 2 — Visual direction

Full brand palette (reuses existing tokens: parchment, green-dark, gold). Typography stack. Tone: technical, dry, no hype. Reference: existing Armstrong proposal for style baseline.

Block 3 — Site map + deployment target

6 pages. canary.growdirect.io/rapidpos. Multi-page static HTML. Each page = one artifact. List of pages with one-line purpose.

Block 4 — Shared components spec

Nav bar (logo, page links, CTA). Footer. Code block styling. Architecture diagram conventions. Tells Claude.ai what to reuse across pages.

Blocks 5–10 — Per-page briefs

One block per page. Each contains: purpose, audience state of mind, hero/headline, sections with actual content (not placeholders), design notes. Claude.ai generates one artifact per block.

Page 1: Overview (index)
Page 2: Architecture — How It Works
Page 3: MCP Endpoint Reference
Page 4: VAR Quickstart
Page 5: Store of the Future 2030 (presentation mode)
Page 6: Armstrong — Applied Pitch (condensed proposal, solution-first)

Block 11 — Generation instructions

Explicit instructions to Claude.ai: generate each page as a self-contained HTML artifact. Share CSS via a <style> block. No frameworks, no CDN, no build step. Inline SVG for diagrams.

A

One big brief → generate all pages in sequence

Full brief in one .md. Feed to Claude.ai once. It generates page 1, you say "next," it generates page 2, and so on. Keeps CSS consistent across all pages since it remembers the prior artifacts.

B

One brief per page

The .md has a top-level shared-design section, then each page section is self-contained enough to paste independently. More portable — send just the Armstrong pitch section to a different Claude.ai session if needed.
