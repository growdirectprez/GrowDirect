The Problem

A single blueprint page contains dozens of dimensions, annotations, and construction details crammed together. Sending a whole page to vision AI and asking "extract all dimensions" produces unreliable, incomplete results. Faded 1958 hand-drawn plans make it worse.

The Proposed Approach: Surgical Cropping

📄
1. Load Page
PDF → high-res image
(300 DPI)
✂️
2. Crop Region
Select one detail:
a wall, a footing, a window
🔍
3. Extract
Vision AI reads JUST
this crop's dimensions
✓
4. Verify
Human confirms or
corrects each reading

Repeat for every component on every page → accumulate into spatial model

How granular should the crops be?

This determines how many extraction passes per blueprint page

A

By Construction System

One crop per system per page. Foundation plan → one crop for footings, one for slab, one for stem walls. ~3-6 crops per page.

B

By Individual Element

One crop per wall, per footing, per opening. Foundation plan → one crop per footing run. ~10-20 crops per page. Most accurate but most work.

C

Adaptive — Start Coarse, Zoom In

First pass: whole page overview to identify regions. Second pass: crop each region. Third pass: zoom into problem areas where AI struggled. Let the AI's confidence drive how deep you go.
